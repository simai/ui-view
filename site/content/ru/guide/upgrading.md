# Обновление версий

Каждый выпуск набора собран и проверен над одним выпуском SIMAI Framework
и называет наименьший Core, с которым работает. Обновление — это смена
номера в строке подключения и проверка своих страниц.

## Перед началом

- Прочитайте [историю изменений](../changes/) между вашей и новой версией.
- Посмотрите в таблице [версий и совместимости](../connection/#версии-и-совместимость),
  какой Core нужен новой версии.

## Шаги

1. Если страница подключает набор без версии (`data-sf-sets="view"`),
   Loader уже берёт самый новый выпуск, подходящий к вашему Core.
   Для рабочего сайта лучше закрепить версию:

   ```html
   <script src="https://cdn.jsdelivr.net/npm/@simai-studio/ui@5.20261105.1447/distr/core/js/core.min.js" data-sf-sets="view@1.1.0"></script>
   ```

2. Поменяйте номер набора — и, если новая версия требует, номер SIMAI
   Framework в адресе Core.

3. Замените прежние имена, пока они работают (см. ниже), и проверьте
   консоль браузера: каждое прежнее имя отмечается в `SF.deprecations`.

4. Пройдите свои экраны: поиск, страницы, действия над строками, карточку.

## Результат

Страницы работают на новой версии, а в `SF.deprecations` нет записей о
прежних именах.

### Прежние имена

Компоненты набора раньше входили в пакет SIMAI Pro под другими тегами. До
**2027-01-01** прежние имена работают и отмечаются в `SF.deprecations`:

| Сейчас | Прежде |
|:---|:---|
| `<sf-view>` | `<sf-data-view>` |
| `<sf-view-table>` | `<sf-table>` |
| `<sf-view-properties>` | `<sf-property-view>` |
| правила `cl-view`, `cl-view-table`, `cl-view-properties` | `cl-data-view`, `cl-table`, `cl-property-view` |
| события `sf-view-*` | `sf-data-view-*` — приходят с тем же `detail` |
| события `sf-view-table-*` | `sf-table-*` — приходят с тем же `detail` |
| события `sf-view-properties-*` | `sf-property-view-*` |

Старая разметка поднимается как новый элемент, а Loader переадресует
прежнее имя правила к новому. Публичные CSS-переменные (`--sf-data-view-*`,
`--sf-table-*`, `--sf-property-view-*`) и имена классов **не
переименованы** и остаются такими.

Пакет SIMAI Pro (`pro`) пока продолжает поставлять эти компоненты; он
станет сборкой из наборов. Новым страницам подключайте набор `view`.
