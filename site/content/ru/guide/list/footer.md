# Подвал и страницы

**Подвал списка** — строка под записями: сколько записей на экране и
сколько всего, размер страницы и переход по страницам. У таблицы над этой
строкой стоит кнопка «Показать ещё» — она добавляет к списку следующую
страницу. У канбана строки страниц нет: каждая колонка догружает записи
своей кнопкой «Показать ещё».

  B["Канбан"] --> F2["«Показать ещё» в каждой колонке"]
:::

## Пример

Внизу таблицы — «Показать ещё», под ней строка: слева «1–20 из 60», по
центру страницы, справа «По 20». Нажмите «Показать ещё» — к записям
добавится следующая страница, а строка станет «1–40 из 60». Выберите другой
размер страницы или перейдите на следующую — строка под примером покажет,
что запросил список. В «Вид» → «Подгрузка» выберите, как таблица идёт
дальше. Выберите в полосе представления «Канбан» — у каждой колонки будет
своя «Показать ещё».

## Как это устроено

### Строка подвала

```text
                     Показать ещё 20
41–60 из 240           ‹ [3] из 12 ›           По 20 ▾
```

- **Показать ещё** — кнопка во всю ширину под последней строкой: добавляет
  к записям следующую страницу, диапазон растёт («1–40 из 240»).

- **Диапазон** — слева: какие записи на экране из всех, что насчитало
  приложение (`total` в ответе). Если приложение сказало, что число
  приблизительное (`total_exact: false`), перед ним стоит «~».
- **Страницы** — по центру: поле с номером страницы, «из N» и стрелки: в
  начало, назад, вперёд, в конец. Кнопки на краях гаснут, а не пропадают,
  поэтому строка не меняет ширину, пока человек листает.
- **Размер страницы** — справа, тихая кнопка «По 20» с меню: по 10, 20, 50
  или 100 записей. По умолчанию — 20.

На узком экране переход по страницам встаёт своей строкой по центру, под
диапазоном и размером страницы.

```html
<sf-view aria-label="Заказы" preferences-key="shop.orders">
  <sf-view-table slot="content" aria-label="Заказы"></sf-view-table>
  <sf-pagination slot="pagination" page-sizes="10,20,50,100"></sf-pagination>
</sf-view>
```

### Размер страницы запоминается

Выбранный размер страницы человек сохраняет, как и сортировку: с
`preferences-key` у `sf-view` первый запрос при следующем заходе уже
просит его (`per_page`). Если страница не задала ни `page-size`, ни
`page-sizes`, список просит 20 записей, а меню размеров — «По 10 · По 20 ·
По 50 · По 100».

### Подгрузка: как таблица идёт дальше

В «Вид» → «Подгрузка» человек выбирает, как таблица показывает следующие
записи; выбор действует во всех его таблицах. Страница задаёт начальный
выбор атрибутом `paging` у `sf-view`:

| «Подгрузка» | `paging` | Что под таблицей |
|:---|:---|:---|
| Страницами | `pages` | только строка страниц |
| «Показать ещё» | `more` | только кнопка «Показать ещё» во всю ширину |
| Вместе | `both` | кнопка, под ней строка страниц; по умолчанию |
| Бесконечно | `endless` | следующая страница загружается, когда конец списка появляется на экране; для таблиц не рекомендуется |

```html
<sf-view aria-label="Заказы" paging="pages">…</sf-view>
```

`layouts.table.paging` в документе представления важнее атрибута.

### Канбан и карточки

- Каждая колонка канбана заканчивается своей кнопкой «Показать ещё»,
  которая догружает записи этой колонки. Строки страниц у канбана нет.
- У карточек та же строка, что у таблицы: «Показать ещё», «1–24 из 48»,
  страницы и размер страницы под сеткой — и после переключения с таблицы.
  У карточек своя «Подгрузка» в «Вид», с теми же значениями.

У пустого, упавшего или закрытого списка подвала нет.

### Что приходит приложению

| Способ | Что в запросе |
|:---|:---|
| Таблица | `page`, `per_page`; «Показать ещё» просит следующую страницу (`page` + 1) |
| Канбан | `window: {lanes, per_lane}`; «Показать ещё» в колонке — `window: {lane, cursor}` |
| Карточки | `window: {page, per_page}` |

### По шагам: страницы с сервера

1. Поставьте строку страниц в слот `pagination` и перечислите размеры,
   которые можно выбрать:

   ```html
   <sf-pagination slot="pagination" page-sizes="10,20,50,100" top="false"></sf-pagination>
   ```

2. На сервере верните ровно одну страницу: записи с
   `(page - 1) × per_page` по `page × per_page`.

3. Сообщите общее число записей в `total` — подвал напишет «41–60 из 240».
   Если считать все записи дорого, не присылайте `total`, а присылайте
   `has_next: true`, пока есть следующая страница: строка страниц
   предложит двигаться вперёд, не зная числа.

4. Если число известно приблизительно, добавьте `total_exact: false`:
   подвал покажет «~N». Чтобы человек мог узнать точное число, объявите
   возможность `count-on-request` и ответьте на намерение `query.count`.

Как считать и отдавать большие выборки — в разделе [Большие объёмы
данных](/ru/guide/server/large-data/).

## Почему так

Одна строка снизу не отнимает места у записей и всегда на одном месте.
«Показать ещё» оставляет на экране то, что человек уже видел, а страницы
позволяют перейти сразу далеко. Колонки канбана читаются потоком, поэтому
их проще догружать, чем листать.

## Ограничения

- Размеры страницы — только из списка `page-sizes`.
- Без `total` диапазон показывает записи на экране, а число всех — нет.
