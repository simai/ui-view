# Карточка записи

Карточка записи `sf-view-properties` показывает одну запись по разделам и
группам. Из списка она открывается одним из трёх способов: панелью рядом со
списком, панелью поверх списка на узком экране или прямо на странице.

:::

## Рядом со списком

У списка атрибут `record-card` называет `id` панели на странице:

```html
<sf-view aria-label="Заказы" record-card="order-card">…</sf-view>
<sf-view-properties id="order-card" panel hidden mode="view"></sf-view-properties>
```

Запись, открытая из таблицы, доски, карточек или календаря, открывается в
этой панели. При ширине от 64rem панель встаёт **рядом со списком**, без
затемнения: список сужается и остаётся рабочим, нажатие на другую запись
открывает её в той же панели, а открытая запись в списке отмечена заливкой.
Alt+↓ и Alt+↑ в карточке переходят к следующей и предыдущей записи в
порядке списка. Крестик и Escape закрывают панель и возвращают фокус строке.

На более узком экране та же панель открывается **поверх списка**.

## На странице

Карточку можно поставить и в страницу, без атрибута `panel`. Тогда страница
сама решает, когда её показать: например, отменяет событие `sf-view-open` и
пишет карточке `record-id`. В примере это кнопка «На странице».

## Разделы

Где стоят разделы записи, зависит от места карточки (`sections-as`):

| Место | Разделы | Значение по умолчанию |
|:---|:---|:---|
| Панель сбоку | списком слева, поля справа | `list` |
| На странице | вкладками сверху | `tabs` |
| Телефон | список разделов; раздел открывается своим экраном со стрелкой «←» | — |

Записанное значение `sections-as` сильнее места.

## Ширина панели

Ширина панели — ступень `panel-size`, по ширине текста:

| `panel-size` | Обычная плотность | Компактная |
|:---|:---|:---|
| `1/2` | 352 px | 308 px |
| `1` | 416 px | 364 px |
| `2` — по умолчанию | 512 px | 448 px |
| `full` | весь экран | весь экран |

Панель с разделами слева шире на колонку разделов, чтобы полям осталась их
ширина. Ширину не задают пикселями: только ступенью.
