# Массовые действия

Человек отмечает несколько записей и выполняет с ними одно действие:
отметить оплаченными, отправить напоминание, удалить. Список показывает
полосу действий, пока что-то отмечено, а выполняет действие приложение.

:::example {id="guide/bulk-orders" label="Действия с отмеченными заказами"}
:::

## Отметить записи

Флажок в начале строки отмечает запись, флажок в заголовке — всю страницу.
Shift с щелчком отмечает диапазон, Пробел — строку под фокусом. В карточках
флажок стоит на карточке. Отмеченные записи остаются отмеченными при смене
способа показа.

## Полоса действий

Пока что-то отмечено, внизу списка стоит полоса: «Выбрано N», действия и
крестик «Снять выбор». Действия перечисляет страница в атрибуте `actions`
строки страниц:

```html
<sf-pagination slot="pagination" top="false"
  actions="paid:Отметить оплаченными|remind:Напомнить клиенту"></sf-pagination>
```

Сборка без разметки передаёт их свойством `bulkActions` представления:
`[{id, label}]`.

## Запрос и результат

Нажатое действие приходит приложению запросом `bulk.apply_selected`: какое
действие (`action_id`), какие записи (`record_ids`) и их ревизии
(`revisions`) — чтобы приложение отказало всем, если запись успела
измениться. Приложение отвечает `applied` с сообщением или `conflict` со
списком изменившихся записей.

```js
if (intent === 'bulk.apply_selected') {
  const done = await markPaid(payload.record_ids, payload.revisions);
  return {answer: 'applied', message: `Отмечено оплаченными: ${done.length}`};
}
```

Сообщение — строка результата: в примере она под списком.
