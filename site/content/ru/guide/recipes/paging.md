# Страницы

Строка страниц `sf-pagination` под списком показывает, сколько записей
найдено, и переключает страницы и размер страницы. Каждый переход —
новый `query.change` с номером страницы `page` и размером `per_page`.

## Перед началом

- Список загружается с сервера через `sf-view`.

## Шаги

1. Поставьте строку страниц в слот `pagination` и перечислите размеры,
   которые можно выбрать:

   ```html
   <sf-pagination slot="pagination" page-sizes="10,25,50,100" top="false"></sf-pagination>
   ```

2. На сервере верните ровно одну страницу: записи с
   `(page - 1) × per_page` по `page × per_page`.

3. Сообщите общее число записей в `total`. Если считать все записи дорого,
   не присылайте `total`, а присылайте `has_next: true`, пока есть
   следующая страница, — строка страниц предложит двигаться вперёд, не зная
   числа.

4. Если число известно приблизительно, добавьте `total_exact: false`:
   строка покажет «~N». Чтобы человек мог узнать точное число, объявите
   возможность `count-on-request` и ответьте на намерение `query.count`.

## Результат

Строка страниц показывает «Всего: 640», номера страниц и выбор размера.
Выбранный размер запоминается, если у представления есть
`preferences-key`, и первый запрос при следующем заходе уже просит его.
Посмотреть, как это работает, можно на экране «Склад» [главной
страницы](/ru/).
