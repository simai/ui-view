# Выбор строк и действия над ними

Человек отмечает строки флажками и выбирает действие внизу списка:
«Отметить оплаченными», «Взять в работу», «Удалить». Представление
отправляет приложению одно намерение со всеми отмеченными записями и их
ревизиями.

## Перед началом

- Список загружается с сервера через `sf-view`; у записей есть `revision`.

## Шаги

1. Перечислите действия в атрибуте `actions` строки страниц: пары
   `код:подпись` через вертикальную черту:

   ```html
   <sf-pagination slot="pagination" actions="paid:Отметить оплаченными|remind:Напомнить клиенту"></sf-pagination>
   ```

   Колонка флажков есть у таблицы по умолчанию. Когда отмечена хотя бы одна
   строка, внизу появляется панель: число отмеченных, выбор действия и
   кнопка «Применить».

2. Ответьте на намерение `bulk.apply_selected`. В нём код действия, `id`
   отмеченных записей и ревизии, которые видел человек:

   ```json
   {"action_id": "paid", "record_ids": ["i-501", "i-504"], "revisions": {"i-501": "1", "i-504": "3"}}
   ```

3. Проверьте права и ревизии. Если хотя бы одна запись изменилась, пока
   человек на неё смотрел, откажите всему пакету — ответом `conflict` со
   списком устаревших записей:

   ```json
   {"answer": "conflict", "conflicts": [{"id": "i-504", "current_revision": "4"}]}
   ```

4. Выполните действие и ответьте `applied`. Представление перечитает
   страницу; можно вернуть и только изменённые записи в `data.records` —
   тогда перерисуются ровно они.

Отметьте несколько счетов и выберите действие внизу списка:

Действие над пакетом всегда приходит как `bulk.apply_selected`, даже если
отмечена одна строка. Его код не обязан быть в `actions` записи — право на
пакет проверяет сервер. Действие над всеми записями под фильтром, а не
только отмеченными, — отдельное намерение `bulk.apply_under_filter` с
подтверждённым числом записей (возможность `bulk-under-filter`).
