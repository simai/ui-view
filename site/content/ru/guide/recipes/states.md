# Пусто, загрузка и ошибка

У списка четыре состояния данных: `loading` — данные идут, `populated` —
записи есть, `empty` — записей нет, `error` — загрузить не удалось.
`sf-view` переключает их сам по ответам приложения; таблице, наполненной
напрямую, состояние задаёт страница.

## Перед началом

- Подберите слова для пустого списка и ошибки: «Поставок пока нет» лучше,
  чем «Нет данных».

## Шаги

1. Задайте слова атрибутами таблицы:

   ```html
   <sf-view-table aria-label="Поставки" empty-text="Поставок пока нет"
     error-text="Не удалось загрузить поставки" retry-text="Повторить"></sf-view-table>
   ```

2. Если таблица наполняется напрямую, ставьте `data-state="loading"` перед
   запросом и `data-state="error"`, если он не удался. По кнопке повтора
   таблица отправляет событие `sf-view-table-refresh` — загрузите данные
   снова. Значение `auto` (по умолчанию) показывает строки, если они есть,
   и пустое состояние, если их нет.

3. В `sf-view` состояние задаёт ответ приложения. `refused` с причиной
   доступа (`forbidden` и похожие) убирает строки, панель и выбор:
   человеку нечего показывать. `refused` по другой причине — например,
   слишком длинный поиск — оставляет панель и введённый запрос, чтобы его
   можно было исправить. `unavailable` показывает ошибку и кнопку повтора.

4. Пишите причину для человека в `message`: представление покажет её
   заголовком пустого или ошибочного состояния, как текст.

## Результат

Переключите состояние кнопками над таблицей. В состоянии «Ошибка» нажмите
«Повторить» — страница загрузит данные снова.
