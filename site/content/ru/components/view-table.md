# Умная таблица sf-view-table

`sf-view-table` показывает записи таблицей или компактным списком. Каждая
колонка называет тип своих значений, и таблица сама рисует подходящую ячейку:
ссылку на запись, выбор цветной меткой, дату, число, файл, цвет. Поиск,
сортировка, настройка колонок и выбор строк встроены.

Таблицу можно наполнить напрямую — `setColumns()` и `setRows()`, — или
поставить внутрь представления данных [`sf-view`](../view/), которое берёт
записи у приложения и само передаёт их таблице.

## Компактный список

`layout="list"` рисует запись строкой: название и поля с наибольшим
приоритетом (`priority`), их число задаёт `list-fields`. При
`layout="auto"` таблица сама становится списком на узком экране.

## Параметры

| Атрибут | Что задаёт |
|:---|:---|
| `aria-label` | доступное имя таблицы |
| `layout` | `table`, `list` или `auto` (таблица, на узком экране — список) |
| `list-fields` | сколько полей показывает строка списка |
| `search-placeholder` | подсказка в поле поиска |
| `table-settings-key` | ключ, под которым таблица помнит колонки и сортировку |

| Метод | Что делает |
|:---|:---|
| `setColumns(columns)` | задаёт колонки: `key`, `label`, `propertyType`, `role`, `sortable`, `priority`, `options` |
| `setRows(rows)` | задаёт записи; у каждой есть `id`, значения лежат под ключами колонок |
| `setSort(sort)` | задаёт сортировку |

Полный перечень атрибутов, событий и методов — в паспорте компонента
`package/src/smart/view-table/component.json` репозитория набора.

## Прежний тег

До 2027-01-01 прежний тег `sf-table` работает как `sf-view-table`: старая
разметка не ломается, а каждое использование отмечается в
`SF.deprecations`. Так же работают `sf-data-view` и `sf-property-view`.
