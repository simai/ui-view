# Карточка записи sf-view-properties

`sf-view-properties` показывает одну запись: её свойства в группах и
разделах, каждое своим типом поля — строка, текст, выбор, дата, флажок,
ссылка на другую запись, файл. Группу можно открыть на правку и сохранить.

Карточка, как и `sf-view`, не хранит данных. Она просит запись у приложения
(`record.load`), рисует ответ и отправляет изменённые значения группы
(`group.save`); приложение отвечает записью с новой ревизией.

## Карточка клиента

Нажмите «Изменить» у группы, поменяйте значение и сохраните: приложение
примера запомнит его и ответит следующей ревизией.

## Параметры

| Атрибут | Что задаёт |
|:---|:---|
| `record-id` | какую запись показать; смена значения загружает другую запись |
| `aria-label` | доступное имя карточки |
| `panel` | карточка как боковая панель |
| `full` | карточка на всю область |

| Намерение | Что отвечает приложение |
|:---|:---|
| `record.load` | `applied` с записью: `label`, `revision`, `sections` → `groups` → `fields` |
| `group.save` | `applied` с записью новой ревизии, `conflict` или `refused` |
| `view.profile`, `view.rename`, `view.delete` | именованные виды карточки, если приложение заявило возможность `view-settings` |

Поле описывают `key`, `label`, `propertyType`, `value`, `width`
(`half` или `full`), для выбора — `options`.
