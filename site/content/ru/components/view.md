# Представление данных sf-view

`sf-view` связывает таблицу с приложением. Компонент не хранит данные: когда
человек ищет, сортирует или листает страницы, он передаёт приложению
намерение (`query.change`), а приложение отвечает записями. Ответ
`sf-view` передаёт таблице `sf-view-table` и строке страниц `sf-pagination`.

Приложение подключается методом `setHostPort(host)`: объект с версией порта,
списком возможностей и функцией `raise(intent, payload)`. Порт —
`simai.dataview-port`, компонент принимает его версии с 1.0.0 по 1.13.0.

## Представление с приложением

Здесь приложение — несколько строк JavaScript с массивом проектов. Кнопки
над таблицей переключают ответ приложения: данные, отказ в доступе или сбой
сервера. Представление показывает каждый ответ по-своему.

## Намерения

| Намерение | Когда отправляется | Что отвечает приложение |
|:---|:---|:---|
| `query.change` | поиск, сортировка, фильтр, страница | `applied` с колонками, записями и `total`; `refused` или `unavailable` |
| `record.open` | человек открыл запись | `applied`; переход делает приложение |
| `record.mutate` | действие над строкой (`row_actions`) | `applied` с изменёнными записями |
| `settings.save_personal` | человек сохранил свои колонки | `applied` с новой ревизией или `conflict` |

Ответ `applied` на `record.mutate` несёт только изменённые записи:
представление перерисовывает ровно эти строки.
