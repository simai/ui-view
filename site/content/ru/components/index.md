# Компоненты

Справочник компонентов набора SIMAI View. На странице каждого компонента —
описание, живые примеры, атрибуты, события, методы, CSS-переменные и
доступность; справочная часть собрана из манифеста компонента в выпуске.

## Компоненты набора

| Компонент | Элемент | Что делает |
|:---|:---|:---|
| [Представление данных](view/) | `sf-view` | берёт записи у приложения через порт и показывает их с поиском, фильтрами, сортировкой, страницами, выбором строк и представлениями |
| [Шапка списка](view-head/) | `sf-view head="list"` | название, представления и способ показа, фильтр по полям, поиск и «Создать» над списком |
| [Умная таблица](view-table/) | `sf-view-table` | типизированные ячейки, колонки, меню строки и колонки, выбор строк; на узком экране — компактный список |
| [Доска](view-board/) | `sf-view-board` | записи колонками по значению одного поля (статус, выбор, человек); перенос карточки меняет поле, число и суммы в шапке колонки; предварительная версия |
| [Карточки](view-cards/) | `sf-view-cards` | записи сеткой карточек: обложка, название и до четырёх полей; колонок столько, сколько вмещает ширина; предварительная версия |
| [Календарь](view-calendar/) | `sf-view-calendar` | записи на днях их даты: месяц, неделя, день, список; перенос и растягивание мышью, пальцем и клавишами; предварительная версия |
| [Карточка записи](view-properties/) | `sf-view-properties` | свойства одной записи в разделах и группах, просмотр и правка |
| [Блок в потоке](view-flow/) | `sf-view-flow` | несколько свойств записи в потоке (чат, лента): показать данные или попросить заполнить поля и отправить; предварительная версия |
<!-- /components:generated -->

Внутри компоненты используют кнопки, поля, меню, метки и строку страниц
SIMAI Framework — их описывает [документация SIMAI Framework](https://ui.simai.io/).

## Как читать справочник

- **Атрибуты** пишутся в разметке; каждому соответствует свойство элемента
  в camelCase.
- **События** приходят на сам элемент и всплывают; данные события — в
  `event.detail`.
- **Методы** вызывают после `customElements.whenDefined('<тег>')`.
- **Прежние имена** тегов и событий работают до 2027-01-01 — см.
  [Обновление версий](/ru/guide/upgrading/).
