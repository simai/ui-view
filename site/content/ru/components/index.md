# Компоненты

Справочник компонентов набора SIMAI View. На странице каждого компонента —
описание, живые примеры, атрибуты, события, методы, CSS-переменные и
доступность; справочная часть собрана из манифеста компонента в выпуске.

## Представления данных

| Компонент | Элемент | Что делает |
|:---|:---|:---|
| [Представление данных](views/view/) | `sf-view` | берёт записи у приложения через порт и показывает их с поиском, фильтрами, сортировкой, страницами, выбором строк и сохранёнными видами |
| [Шапка списка](views/view-head/) | `sf-view head="list"` | название и число записей, виды и способ показа, фильтр по полям, поиск и «Создать» над списком |
| [Умная таблица](views/view-table/) | `sf-view-table` | типизированные ячейки, колонки, меню строки и колонки, выбор строк; на узком экране — компактный список |
| [Доска](views/view-board/) | `sf-view-board` | записи колонками по значению одного поля (статус, выбор, человек); перенос карточки меняет поле, число и суммы в шапке колонки; предварительная версия |
| [Карточки](views/view-cards/) | `sf-view-cards` | записи сеткой карточек: обложка, название и до четырёх полей; колонок столько, сколько вмещает ширина; предварительная версия |
| [Календарь](views/view-calendar/) | `sf-view-calendar` | записи на днях их даты: месяц, неделя, день, список; перенос и растягивание мышью, пальцем и клавишами; предварительная версия |
| [Карточка записи](views/view-properties/) | `sf-view-properties` | свойства одной записи в разделах и группах, просмотр и правка |
| [Блок в потоке](views/view-flow/) | `sf-view-flow` | несколько свойств записи в потоке (чат, лента): показать данные или попросить заполнить поля и отправить; предварительная версия |

Внутри компоненты используют кнопки, поля, меню, метки и строку страниц
SIMAI Framework — их описывает [документация SIMAI Framework](https://ui.simai.io/).

## Как читать справочник

- **Атрибуты** пишутся в разметке; каждому соответствует свойство элемента
  в camelCase.
- **События** приходят на сам элемент и всплывают; данные события — в
  `event.detail`.
- **Методы** вызывают после `customElements.whenDefined('<тег>')`.
- **Прежние имена** тегов и событий работают до 2027-01-01 — см.
  [Обновление версий](/ru/guide/upgrading/).
