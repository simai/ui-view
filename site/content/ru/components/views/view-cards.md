# Карточки

:badge[sf-view-cards]{variant=main scheme=on-surface size=1} :badge[Версия 1.0.5]{variant=tonal scheme=neutral size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

Карточки показывают записи сеткой: у каждой — обложка (картинка из поля-файла), название и до четырёх полей. Колонок столько, сколько вмещает ширина: на телефоне одна, у маленьких карточек две. Под сеткой — «Показать ещё»: приложение отдаёт следующие 24 записи, сетка их добавляет.

Обычно карточки рисует [представление данных](../view/) с `layout="cards"`: оно просит у приложения окно `{page, per_page}`, передаёт ответ карточкам и отвечает на их события — открыть запись, отметить, выполнить действие над отмеченными. Нажатая карточка открывает [карточку записи](../view-properties/) рядом со списком, сетка сужается.

## Пример

Товары магазина сеткой карточек. Нажмите на карточку или Enter — приложение
откроет запись. Стрелки ходят по сетке по рядам, Пробел отмечает карточку
(появится панель действий над отмеченными), Shift+F10 открывает её меню,
Escape снимает отметку. «Показать ещё» добавляет следующие 24 записи.

## Как устроено

Карточки не хранят данных и не ходят в сеть. Внутри
[представления данных](../view/) порядок такой:

1. Представление просит у приложения **окно** — тот же `query.change`, что
   у таблицы, с полем `window`: `{page: 1, per_page: 24}`.
2. Приложение отвечает записями этой страницы, числом всех записей под
   фильтром и настройками карточек.
3. «Показать ещё» просит следующую страницу (`{page: 2, per_page: 24}`);
   карточки добавляются в конец сетки, фокус остаётся на месте.
4. Нажатие на карточку, отметка и действие над отмеченными — события
   карточек; представление превращает их в намерения приложения.

### Ответ на окно

```js
{
  answer: 'applied',
  sequence: payload.sequence,
  data: {
    columns: [/* поля записи, как у таблицы */],
    records: [/* до 24 записей страницы */],
    total: 240,
    view_config: {layouts: {cards: {/* настройки карточек, ниже */}}},
  },
}
```

Когда приложение не знает числа записей, вместо `total` оно отвечает
`has_next: true` — «Показать ещё» остаётся, пока записи есть.

## Настройки карточек

Настройки приходят в ответе приложения, в `view_config.layouts.cards`:

```json
{
  "cover_field": "photo",
  "cover": {"fit": "cover", "ratio": "4:3"},
  "title_field": "title",
  "card_fields": ["sku", "category", "price", "stock"],
  "card_labels": false,
  "size": "m",
  "density": "default",
  "more": "button"
}
```

| Ключ | Что задаёт |
|:---|:---|
| `cover_field` | поле-файл с картинками (шаблоны `image`, `image_card`, `image_list`) или `null` — без обложки; не задано — первое поле с картинками |
| `cover` | `fit`: `cover` — обрезать по рамке, `contain` — целиком на подложке; `ratio`: `1:1`, `4:3`, `3:4`, `16:9` |
| `title_field` | поле названия: две строки, дальше «…» |
| `card_fields` | до четырёх полей под названием; их рисуют общие отрисовщики полей SIMAI Framework |
| `card_labels` | показывать подписи полей; без них подпись читает экранный диктор |
| `size` | `s`, `m`, `l` — наименьшая ширина карточки (12, 15 и 20rem); колонок столько, сколько вмещает ширина |
| `density` | `default` или `compact` |
| `more` | `button` — «Показать ещё» под сеткой |

Группировки у карточек нет: записи по значению поля раскладывает доска
(`layout="board"`).

## Обложка

Обложка — первая картинка поля `cover_field`. Рамка обложки держит место
до загрузки картинки, картинка грузится, только когда карточка близко к
экрану, — страница не прыгает. У записи без картинки рамка говорит «Нет
фото»; у файла другого вида (PDF, таблица) — значок по типу файла.
Приложение может дать уменьшенные копии: `thumb: {240: '…', 480: '…', 960: '…'}`
— карточка возьмёт копию по ширине рамки.

## Клавиши, телефон и карточка записи

- Сетка — одна остановка Tab. Стрелки ходят по рядам, как нарисовано;
  Home и End — к началу и концу ряда, Ctrl+Home и Ctrl+End — к первой и
  последней карточке.
- Enter открывает запись, Пробел отмечает карточку, Shift+Пробел — от
  прошлой отметки до этой; Shift+F10 открывает меню карточки; Escape
  снимает отметку.
- Отмеченные показывают панель действий приложения над ними.
- На телефоне у размеров M и L одна колонка, у S — две.
- У представления с атрибутом `record-card` нажатая карточка открывает
  [карточку записи](../view-properties/) рядом со списком: сетка сужается
  (на 1440 px — с пяти колонок до трёх), открытая карточка отмечена.

## Пустые состояния

Записей нет — «Записей пока нет» и «Создать», если приложение разрешает
создавать; по поиску или фильтру ничего нет — «Ничего не найдено» и
«Сбросить фильтр». Ошибку и отсутствие доступа карточки показывают так же,
как таблица.

## Параметры

Справочник собран из манифеста компонента в сборке-кандидате набора (`simai/ui-view@008345776e8f`) и обновляется вместе с выпуском. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`.

| | |
|:---|:---|
| Тег | `<sf-view-cards>` |
| Назначение | Раскладка карточек набора представлений: записи карточками в сетке, колонок столько, сколько вмещает ширина; обложку рисует раскладка, под ней — название и до четырёх полей на месте «Кратко»; «Показать ещё» добавляет следующую страницу. sf-view с layout="cards" рисует её там, где автор её включил. |
| Контракт | `smart.view-cards`, версия `1.0.5` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `size` — `string`, по умолчанию `1/2`, значения: `1/2`, `1`. Ступень размера текста и кнопок карточек.
- `card-size` — `string`, по умолчанию пусто, значения: пусто, `s`, `m`, `l`. Размер карточки поверх size из layouts.cards: s, m, l — наименьшая ширина карточки 224, 288 и 352 px на компьютере (шаги шкалы ширин --sf-measure-28, --sf-measure-36, --sf-measure-44); колонок столько, сколько вмещает ширина. Пусто — размер из настроек (m).
- `selectable` — `boolean`, по умолчанию `true`. У карточек есть флажок выбора; Пробел отмечает карточку, Shift+Пробел — диапазон.
- `creatable` — `boolean`, по умолчанию `false`. Пустой список предлагает «Создать» (событие create).
- `total` — `integer`. Сколько записей под фильтром (total приложения). Не задано — сколько показано.
- `has-next` — `boolean`, по умолчанию `false`. Есть ли следующая страница (has_next ответа). Не задано — total больше, чем показано.
- `count-known` — `boolean`, по умолчанию `true`. false, когда приложение не считает записи: «Показано N» без «из M».
- `current` — `string`, по умолчанию пусто. Запись, открытая в карточке записи рядом со списком: её карточка отмечена.
- `aria-label` — `string`, по умолчанию пусто.
- `records` — `array`, по умолчанию `[]`. Показанные записи в порядке представления: все страницы, запрошенные до сих пор (окно {page, per_page}).
- `fields` — `array`, по умолчанию `[]`. Описания полей (колонки sf-view): среди них поле обложки, поле названия и поля карточки; поля карточки рисуют отрисовщики полей SIMAI Framework.
- `options` — `object`, по умолчанию `{}`. layouts.cards из simai.view-config/1: cover_field (поле-файл или null; по умолчанию первое поле с картинками), cover {fit: cover|contain, ratio: 1:1|4:3|3:4|16:9}, title_field, card_fields (до четырёх), card_labels, size s|m|l, density default|compact, more (button), per_page (24). Группировки нет.
- `actions` — `array`, по умолчанию `[]`. Действия приложения над отмеченными (bulk actions представления); они же в меню карточки для этой записи.
- `selected` — `array`, по умолчанию `[]`. Отмеченные id.
- `empty-context` — `object`, по умолчанию `{}`. Почему список пуст, как это знает sf-view: {kind: no-data|nothing-found|no-access|error, message?}; рисует sf-empty-state.

## События

События приходят на сам элемент и всплывают.

- `sf-view-cards-open` — `detail`: `{ id, trigger: string }`. Нажатие на карточку, Enter или «Открыть» в её меню (слово open; trigger pointer|keyboard|menu|api): приложение открывает карточку записи (sf-view-properties рядом со списком).
- `sf-view-cards-select` — `detail`: `{ ids: array }`. Отметка изменилась (слово select).
- `sf-view-cards-more` — `detail`: `{ page: number, offset: number, per_page: number }`. «Показать ещё»: приложение отвечает следующей страницей; sf-view добавляет её (records), приложение без sf-view вызывает appendRecords.
- `sf-view-cards-menu` — `detail`: `{ id }`. Меню карточки сейчас откроется (правая кнопка, Shift+F10, «⋯»); отмените событие, чтобы нарисовать своё.
- `sf-view-cards-apply` — `detail`: `{ action, ids: array, scope: string }`. Действие приложения, выбранное для отмеченных (scope selection) или в меню карточки (scope record).
- `sf-view-cards-create` — `detail` не описан. «Создать» в пустом списке.
- `sf-view-cards-reset` — `detail` не описан. «Сбросить фильтр», когда ничего не найдено: приложение очищает поиск и фильтры.
- `sf-view-cards-refresh` — `detail` не описан. «Повторить» после неудачной загрузки.

## Методы

- `appendRecords(args: object)` — возвращает `object`. Следующая страница от приложения (ответ на more) для приложения без sf-view: добавляется в конец, уже показанная запись не повторяется.

## CSS-переменные

Задаются на элементе или на любом предке. Имена сохранили прежнее имя компонента.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-view-cards-min` | `length` | наименьшая ширина карточки |
| `--sf-view-cards-gap` | `length` | промежуток между карточками |
| `--sf-view-cards-cover-background` | `color` | фон рамки обложки |
| `--sf-view-cards-selected-background` | `color` | фон отмеченной карточки |
| `--sf-view-cards-ratio` | `string` | соотношение сторон обложки |

## Доступность

- Роль: `list`.
- Доступное имя: даёт сам компонент.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Список с именем из aria-label и числом записей (иначе «Карточки, N»); одна остановка Tab на сетку, стрелки ходят по рядам, как нарисовано; Enter открывает, Пробел отмечает; вежливая живая область сообщает позицию, отметку и её снятие; после закрытия карточки записи фокус возвращается на её карточку.
