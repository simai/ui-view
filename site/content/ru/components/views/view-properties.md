# Карточка записи sf-view-properties

`sf-view-properties` показывает одну запись: её свойства в разделах и
группах, каждое своим типом поля — строка, текст, число, выбор, дата,
флажок, ссылка на другую запись, файл. Группу можно открыть на правку и
сохранить.

Карточка, как и `sf-view`, не хранит данных. Она просит запись у приложения
(`record.load`), рисует ответ и отправляет изменённые значения группы
(`group.save`); приложение отвечает записью с новой ревизией. Порт —
`simai.property-view-port`.

## Карточка клиента

Нажмите «Изменить» у группы, поменяйте значение и сохраните: приложение
примера запомнит его и ответит следующей ревизией.

## Форма записи

Ответ на `record.load` — запись с разделами, группами и полями:

```json
{
  "answer": "applied",
  "record": {
    "record_id": "k-12",
    "collection": "crm.clients",
    "revision": "7",
    "label": "ООО «Северный ветер»",
    "sections": [{"key": "main", "label": "Клиент", "groups": [
      {"key": "about", "label": "О клиенте", "columns": 2, "fields": [
        {"key": "name", "label": "Название", "propertyType": "string", "width": "half", "value": "ООО «Северный ветер»"},
        {"key": "city", "label": "Город", "propertyType": "string", "width": "half", "value": "Мурманск"}
      ]}
    ]}]
  }
}
```

`sections` обязателен и при одном разделе: раскладку задаёт приложение.
Один раздел рисуется своими группами, без списка разделов. Поле описывают
`key`, `label`, `propertyType`, `value`, `width` (`half` или `full`), для
выбора — `options`, для подсказки — `hint`.

Редкие поля приложение отмечает `rare: true` и присылает всегда: карточка
прячет их, пока не задан `show-rare`.

Список заказов и карточка открытого заказа рядом — экран «Заказы» на

## Параметры

Справочник собран из манифеста компонента в выпуске набора `view-4d7070623fe1` и обновляется вместе с выпуском. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`.

| | |
|:---|:---|
| Тег | `<sf-view-properties>` |
| Назначение | Поля одного объекта по разделам, группам и полям; каждое поле рисует набор рендереров своего типа, данные идут через отдельный порт хоста. Группа редактируется и сохраняется одной ревизией по кнопке, а значение ссылочного поля выбирается из кандидатов элемента постранично. Парный компонент к представлению данных: то показывает набор записей, этот — один объект. |
| Контракт | `smart.view-properties`, версия `1.10.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Шаблон, которым рисуется представление.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `add-field-text` — `string`. Открывает список полей, которые может принять эта группа: тех, что представление никуда не помещает, и тех, что находятся в другой группе.
- `add-group-text` — `string`. Называет кнопку, создающую новую область в конце компоновки.
- `add-section-text` — `string`. Называет кнопку, создающую новый раздел.
- `back-label` — `string`. Элемент управления, который возвращает с экрана раздела к списку разделов; существует только ниже контрольной точки drawer. Выше неё разделы стоят рядом с группами, и возвращаться неоткуда.
- `cancel-configuring-text` — `string`. Называет элемент управления, выходящий из режима компоновки с той компоновкой, с которой в него вошли. Это не сброс: сброс убирает слой, а этот элемент возвращает то, что было.
- `cancel-name-text` — `string`. Называет крестик, оставляющий имя без изменений.
- `cancel-text` — `string`. Подпись действия, которое отбрасывает введённое. Ничего не записано, поэтому отменять нечего.
- `changed-text` — `string`. Подпись перед количеством изменённых полей на панели действий.
- `close-label` — `string`. Доступное имя элемента закрытия панели. По умолчанию — слово на языке страницы; атрибут его переопределяет.
- `collection` — `string`, по умолчанию пусто. Тип объекта в словаре самого хоста. Передаётся обратно хосту и здесь не интерпретируется.
- `collection-icon` — `string`, по умолчанию пусто. Значок рядом с названием коллекции из иконочного шрифта Framework.
- `collection-label` — `string`, по умолчанию пусто. Название коллекции, показанное отдельной строкой над названием записи. Порт передаёт ключ коллекции; читаемое название принадлежит хосту и приходит сюда.
- `configure-hint-narrow-text` — `string`. Выводится на полосе, пока представление настраивается в узкой панели, где список разделов — отдельный экран и поле нельзя перетащить на него.
- `configure-hint-text` — `string`. Выводится на полосе, пока представление настраивается: что делает перетаскивание и что изменение применяется сразу.
- `configure-text` — `string`. Элемент управления, который включает режим настройки. Показывается, только если хост объявляет view-settings и пользователь может записывать хотя бы один слой.
- `conflict-text` — `string`. Текст конфликта, когда хост не передаёт своё сообщение.
- `copy-link-label` — `string`. Доступное имя элемента управления копированием; он появляется, только если хост передал адрес.
- `delete-text` — `string`. Элемент управления, который просит хост удалить запись. Предлагается, только если среди действий записи есть `record.delete`.
- `done-configuring-text` — `string`. Выходит из режима настройки. Изменения уже сохранены, поэтому действие закрывает режим, а не подтверждает что-либо.
- `edit-text` — `string`. Подпись, открывающая группу для редактирования. По умолчанию — слово на языке страницы; атрибут его переопределяет.
- `empty-record-text` — `string`. Выводится вместо полей, когда хост ответил записью без видимого содержимого. Без этой подписи панель выглядит пустой рамкой, которая читается как незавершённая загрузка.
- `empty-text` — `string`. Как читается пустое значение. По умолчанию — слово на языке страницы; атрибут его переопределяет.
- `errors-text` — `string`. Подпись перед количеством ошибок полей, с которыми хост отклонил сохранение.
- `favourite` — `boolean`, по умолчанию `false`. Входит ли запись в избранное пользователя. Звезда сообщает о нажатии и перерисовывается, когда хост устанавливает это значение обратно: хранить признак избранного — задача хоста.
- `favourite-label` — `string`. Доступное имя звезды рядом с названием записи.
- `field-label-text` — `string`. Называет поле в собственных настройках поля, где вводится имя поля в этом представлении. Коллекция хранит своё имя; сброс слоя возвращает его.
- `field-settings-text` — `string`. Называет поверхность с шириной, шаблоном и подсказкой поля во время компоновки представления.
- `hidden-text` — `string`. Скрывает запись в этом слое. Отключено, если её скрыл слой выше; хост указывает это для каждой записи.
- `hide-rare-text` — `string`. Предлагает снова перестать показывать редкие записи.
- `hint-text` — `string`. Подсказка, сохранённая для поля в этом слое.
- `in-this-group-text` — `string`. Называет часть списка добавления полей, которую эта область уже содержит. Список один раз указывает, где поле находится сейчас, над полями, которые там находятся.
- `inherited-text` — `string`. Отметка значения, которое запись не задала и которое унаследовано от пакета или темы. Увидев её, пользователь понимает, что изменение источника изменит и это значение.
- `link-copied-label` — `string`. Название элемента управления копированием, пока на нём отображается галочка. Копирование не оставляет видимого следа, поэтому элемент сообщает о нём столько, сколько это делает буфер обмена Framework, а затем возвращается в исходное состояние.
- `menu-label` — `string`. Доступное имя меню «…» в шапке.
- `move-down-text` — `string`. Перемещает группу на одну позицию вниз.
- `move-up-text` — `string`. Перемещает группу на одну позицию вверх среди групп своего раздела — для тех, кто предпочитает нажимать, а не перетаскивать.
- `new-group-title` — `string`. Имя, с которым создаётся новая область, пока пользователь не ввёл своё.
- `new-section-title` — `string`. Имя, с которым создаётся новый раздел, пока пользователь не ввёл своё.
- `no-match-text` — `string`. Выводится вместо списка, когда поиск не нашёл ни одного поля.
- `open-full-label` — `string`. Доступное имя элемента управления открытием на полной странице; он появляется, только если хост передал адрес.
- `panel` — `boolean`, по умолчанию `false`. Отображается в немодальной панели рядом со списком, из которого открыт объект, а не в рабочей области. Панель немодальная намеренно: список остаётся видимым и доступным.
- `panel-label` — `string`, по умолчанию пусто. Название записи в шапке панели и доступное имя панели. Одного доступного имени недостаточно: панель без видимого заголовка не сообщает, какая запись открыта, а в стеке панелей это пользователю нужнее всего. Полная шапка с коллекцией и звездой — отдельный шаг.
- `panel-size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`, `full`. Ширина панели по собственной шкале панели.
- `size` — `string`, по умолчанию `1`, значения: `1`, `1/2`. Размер представления: текст, подписи полей, заголовки и элементы управления. 1/2 совпадает с таблицей размера 1/2.
- `mode` — `string`, по умолчанию `auto`, значения: `view`, `auto`, `edit`, `create`. Для чего поставлена поверхность. view: показать объект без правки, подвала, удаления и расстановки, что бы человеку ни было разрешено. auto: показать и предложить то, что этому человеку можно (record.edit, действия жизненного цикла, слои, доступные для записи). edit: все группы открыты сразу, одно record.save. create: пустой объект коллекции, прочитанный через record.load в режиме create, все поля открыты, одно record.create.
- `panel-width` — `string`, по умолчанию пусто. Точная ширина панели — для потребителя, макету которого не подходит шаг шкалы. Пустое значение оставляет управление `panel-size`; заданная здесь длина имеет приоритет. Панель в стопке сужается от этой ширины, а не от шкалы.
- `personal-layer-text` — `string`. Слой, который видит только этот пользователь. Он стоит в списке именованных представлений рядом с «Обычный» и «Экспертный», поэтому его название отвечает на тот же вопрос, что и остальные.
- `rare-text` — `string`. Отмечает рядом с именем запись, которую коллекция объявляет редкой.
- `record-id` — `string`, по умолчанию пусто. Какой объект читать. При изменении значения данные перечитываются через порт; от предыдущего объекта компонент ничего не сохраняет.
- `remove-field-text` — `string`. Называет элемент управления, убирающий поле из его области. Поле переходит в неразмещённые, откуда список области может вернуть его, и ничего не теряется.
- `remove-group-text` — `string`. Называет элемент управления, убирающий область из представления. Её поля переходят в неразмещённые, а не удаляются вместе с ней.
- `remove-section-text` — `string`. Называет элемент управления, убирающий раздел из представления. Его области переходят в оставшийся раздел.
- `rename-text` — `string`. Называет карандаш рядом с именем области или раздела во время компоновки представления, а также открываемое им поле.
- `reset-view-ask-text` — `string`. Вопрос, который задаёт сброс перед удалением слоя. Сброс отменяет всё, что пользователь настроил в этом слое, а это больше, чем должно происходить от одного нажатия кнопки рядом с «готово».
- `reset-view-text` — `string`. Возвращает выбранный слой к тому, что лежит под ним.
- `save-name-text` — `string`. Называет галочку, записывающую вводимое имя в слой.
- `save-text` — `string`. Подпись действия, которое сохраняет открытую группу. Одно нажатие — одна ревизия.
- `section-icon-text` — `string`. Называет выбор символа раздела во время компоновки представления.
- `section-icons` — `string`, по умолчанию пусто. Значки, которыми можно пометить раздел, — имена из набора иконок Framework через пробел или запятую. Пустое значение означает собственные сто двадцать иконок компонента, наиболее востребованные в продуктах; хост со своим словарём заменяет их, а не дополняет.
- `sections-as` — `string`, по умолчанию `list`, значения: `list`, `tabs`. Как отображаются разделы: списком рядом с группами — для экрана настроек с большим числом разделов, или рядом вкладок над ними — для записи с несколькими разделами. Сами разделы одинаковы в обоих вариантах.
- `sections-label` — `string`. Доступное имя списка разделов. По умолчанию — слово на языке страницы; атрибут его переопределяет.
- `shared-layer-text` — `string`. Слой, который видят все. Если этот пользователь не может его записывать, слой отображается отключённым с причиной от хоста, а не скрывается — отсутствующий элемент управления воспринимается как отсутствующая функция.
- `show-rare` — `boolean`, по умолчанию `false`. Показывает разделы, группы и поля, которые хост пометил как редкие. Это решение представления: оно ничего не записывает и не меняет значений.
- `show-rare-text` — `string`. Предлагает показать записи, которые коллекция объявляет редкими. Предлагается, только если запись содержит такую.
- `shown-text` — `string`. Называет элемент управления, показывающий или скрывающий запись в этом слое.
- `unplaced-hint-text` — `string`. Устаревший атрибут: значение разбирается и игнорируется. Неразмещённые поля показывает аккордеон Framework, строки подсказки в нём нет.
- `unplaced-title` — `string`. Называет область с полями, которые это представление не помещает ни в одну группу. Отображается только во время компоновки представления.
- `variant-text` — `string`. Выбирает вариант шаблона из предлагаемых хостом для этого поля.
- `view-conflict-text` — `string`. Выводится, когда слой изменился без участия этого пользователя и расположение было прочитано заново.
- `view-denied-text` — `string`. Причина по умолчанию для слоя, который этот пользователь не может записывать; используется, когда хост не передаёт свою.
- `width-text` — `string`. Называет переключатель, при котором поле занимает всю строку, а не половину.
- `view-profile-label` — `string`. Доступное имя элемента выбора, который определяет, какое именованное представление показано. Если не задано, компонент использует язык страницы.
- `add-view-text` — `string`. Текст элемента управления, который создаёт новое именованное представление из расположения на экране. Если не задан, компонент использует язык страницы.
- `new-view-text` — `string`. Название представления в момент создания, пока пользователь его не заменил. Представление «Новое представление» среди четырёх настоящих невозможно отличить от остальных, поэтому имя сразу открывается для ввода.
- `delete-view-text` — `string`. Доступное имя элемента управления, который удаляет именованное представление.
- `last-shared-view-text` — `string`. Почему удаление не предлагается для последнего общего представления: область без представлений ничего не даёт пользователю, у которого нет своих. Показывается на недоступном элементе управления, а не как отказ после нажатия.
- `full` — `boolean`, по умолчанию `false`. Запись как страница: панель рисуется на месте, а не поверх страницы.
- `open` — `boolean`, по умолчанию `true`. Панель видна, пока открыта и не скрыта; `open=false` или `hidden` закрывает её и убирает из стопки, то же самое возвращает её.
- `aria-label` — `string`, по умолчанию пусто.

## События

События приходят на сам элемент и всплывают.

- `sf-view-properties-close` — `detail`: `{ reason, record_id, unsaved_fields: array }`. Панель просит закрыть её (крестиком, Esc или «Отменить») и передаёт, сколько полей будет потеряно: изменённых и не сохранённых или введённых, но ещё не ставших значением.
- `sf-view-properties-open-full` — `detail`: `{ id, address: string, record_id }`. Пользователь запросил этот объект на полной странице по адресу, который передал хост.
- `sf-view-properties-saved` — `detail`: `{ id, revision?: string }`. Факт после применённого сохранения (`group.save` или `record.save`): `{id, revision}`.
- `sf-view-properties-failed` — `detail`: `{ reason: string, message?: string }`. Факт после записи, которую не удалось прочитать, `{reason, message}`: код хоста (`record-unknown` для устаревшей ссылки) и его фраза.
- `sf-view-properties-open` — `detail`: `{ field: string, value: object, answer: string }`. Попросили открыть запись по ссылке, `open: {field, value, answer}`. Прежнее `sf-property-view-open-record` приходит следом до 2026-12-01.
- `sf-view-properties-delete` — `detail`: `{ collection: string, revision: string, answer: string, record_id }`. Удаление записи запрошено и получен ответ, `delete: {record_id, collection, revision, answer}`. Прежнее `sf-property-view-delete-record` приходит следом до 2026-12-01.
- `sf-view-properties-created` — `detail`: `{ collection: string|null, record_id }`. Форма создания создала объект; хост может перейти к его собственному месту. Компонент показывает новый объект в режиме auto.
- `sf-view-properties-cancel` — `detail`: `{ mode, scope?, section?: string, group?: string }`. Правка отменена; то, что человек набрал, отброшено. Поверхность, открытая целиком (правка, создание), не передаёт `scope`, и хост решает, куда это ведёт (панель закрывается); отмена одной группы (с 1.7.0) передаёт `scope: group` с разделом и группой, чтобы хост, следящий за несохранённым, знал, что ввод отброшен.
- `sf-view-properties-state` — `detail`: `{ state: string, message: string }`.
- `sf-view-properties-address-copy` — `detail` не описан. Адрес окна скопирован, или браузер отказал в доступе к буферу обмена.
- `sf-view-properties-favourite` — `detail`: `{ collection: string|null, favourite: boolean, record_id }`. Нажата звезда. Передаёт запись, коллекцию и запрошенное состояние; компонент ничего не меняет, пока хост не установит favourite обратно.
- `sf-host-port-request` — `detail`: `{ component?: object, context?: object }`. Запрашивает у страницы порт хоста — один раз за подключение и только пока у элемента его нет. Общее соглашение для всех компонентов, принимающих `setHostPort`. Ответ — вызов `setHostPort` на цели события, сразу или позже.

Прежние имена событий приходят следом с тем же `detail` и отмечаются в `SF.deprecations`:

`sf-property-view-delete-record` → `sf-view-properties-delete`, `sf-property-view-open-record` → `sf-view-properties-open`, `sf-property-view-close` → `sf-view-properties-close`, `sf-property-view-open-full` → `sf-view-properties-open-full`, `sf-property-view-saved` → `sf-view-properties-saved`, `sf-property-view-failed` → `sf-view-properties-failed`, `sf-property-view-open` → `sf-view-properties-open`, `sf-property-view-delete` → `sf-view-properties-delete`, `sf-property-view-created` → `sf-view-properties-created`, `sf-property-view-cancel` → `sf-view-properties-cancel`, `sf-property-view-state` → `sf-view-properties-state`, `sf-property-view-address-copy` → `sf-view-properties-address-copy`, `sf-property-view-favourite` → `sf-view-properties-favourite`.

## Методы

- `refresh()` — возвращает `object`.
- `load(reason: string)` — возвращает `object`. Повторно читает объект через порт.
- `editGroup(section: string, group: string)` — возвращает `object`. Открывает одну группу для редактирования.
- `cancelEdit()` — возвращает `object`. Закрывает открытую группу, отбрасывая введённое. Ничего не записывает.
- `saveGroup(options: object)` — возвращает `object`. Сохраняет изменённые поля открытой группы одной ревизией.
- `selectSection(key: string)` — возвращает `object`. Открывает один раздел.
- `closePanel(reason: string)` — возвращает `object`. Сообщает, что панель следует закрыть. Решение о закрытии принимает хост.
- `copyAddress()` — возвращает `object`. Копирует адрес, переданный хостом, и сообщает, разрешил ли это браузер.
- `openFullPage()` — возвращает `object`. Сообщает, что этот объект следует открыть на отдельной странице.
- `confirmSave()` — возвращает `object`. Повторить сохранение, которое хост попросил подтвердить, с выданным им отпечатком (порт 1.14.0).
- `cancelConfirmation()` — возвращает `object`. Вернуться к правке из подтверждения, которое запросил хост. Ничего не отправляет и сохраняет все введённые значения.
- `setHostPort(host: object)` — возвращает `object`. Подключает адаптер хоста, предоставляющий `raise(intent, payload, {signal})`, `version` и `capabilities`.
- `changeField(field: object, value: any)` — возвращает `object`. Фиксирует изменение поля; `undefined` отменяет изменение, и сохранение ничего не передаёт для этого поля. Вызывается шаблоном редактирования; хосту он не нужен.
- `getFieldOptionsPage(field: object)` — возвращает `object` | `null`. Страница кандидатов, которую хост последней вернул для одного поля.
- `getFieldOptionSearch(field: object)` — возвращает `string`. Текст, введённый пользователем в элемент выбора одного поля.
- `setFieldOptionSearch(field: object, text: string)` — возвращает `object`. Записывает введённый текст, не обращаясь к хосту.
- `loadFieldOptions(field: object, options?: object)` — возвращает `object`. Запрашивает у хоста страницу вариантов для одного поля.
- `getFieldUploads(field: object)` — возвращает `array`. Файлы одного поля в процессе загрузки, в форме, которую читает sf-file-upload.
- `startFieldUpload(field: object, items: array)` — возвращает `object`. Передаёт хосту выбранные человеком файлы, по одному намерению на файл.
- `retryFieldUpload(field: object, index: number)` — возвращает `object`. Повторно отправляет один файл, загрузка которого не удалась.
- `openReference(field: object, value: any)` — возвращает `object`. Просит хост открыть ссылку, которую активировал человек.

## CSS-переменные

Задаются на элементе или на любом предке. Имена сохранили прежнее имя компонента.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-property-view--sections-width` | `length` | ширина списка разделов |
| `--sf-property-view--title-size` | `length` | размер заголовка записи |
| `--sf-property-view--label-size` | `length` | размер подписи поля |
| `--sf-property-view--value-size` | `length` | размер значения поля |
| `--sf-property-view--group-size` | `length` | размер заголовка группы |
| `--sf-property-view--edge-room` | `length` | отступ открытой панели от края экрана |
