# Календарь

:badge[sf-view-calendar]{variant=main scheme=on-surface size=1} :badge[Версия 1.1.2]{variant=tonal scheme=neutral size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

Календарь показывает записи **на днях их даты**: месяц из шести недель, неделю или день по часам, список по дням. Запись переносят на другой день или время и растягивают за край — мышью, пальцем или клавишами; календарь сразу показывает новое место, а приложение сохраняет его или отказывает и объясняет почему.

Календарь рисует [представление данных](../view/) с `layout="calendar"`: оно просит у приложения записи видимых дней и передаёт календарю. Календарь не хранит данных и не ходит в сеть.

## Пример

Перетащите заказ на другой день или время, потяните нижний край, чтобы
растянуть. Прошедшие дни и воскресенья тускнеют, пока заказ в руке, и
называют причину. Заказ 1013 сервер не переносит — календарь вернёт его на
место и объяснит. «Без даты» открывает заказы без даты: их можно поставить
на день и вернуть обратно.

## Как подключить

Календарь рисует представление данных с `layout="calendar"`. Настройки
календаря — в `options` (или в `layouts.calendar` вида, который отдаёт
приложение):

```html
<sf-view layout="calendar" aria-label="Доставки">
  <sf-view-calendar slot="content"
    options='{"date_field":"start","end_field":"end","color_field":"status","event_fields":["client","amount"]}'>
  </sf-view-calendar>
</sf-view>
```

| Настройка | Что задаёт |
|:---|:---|
| `date_field` | поле начала: `date` — на весь день, `datetime` — со временем |
| `end_field` | поле конца того же типа; растягивание меняет его |
| `mode`, `modes` | с какого режима открыть и какие предложить: `month`, `week`, `day`, `list` |
| `color_field` | поле выбора: событие берёт цвет своего варианта |
| `event_fields` | до трёх полей для строки списка и подсказки события |
| `per_day` | сколько событий видно в дне месяца до «+N» (3) |
| `hours`, `slot` | видимые часы недели и дня и шаг переноса в минутах (30) |
| `weekends` | `show` или `hide` |
| `undated` | `button`, `panel` или `none` — как показать записи без даты |

Начало недели и часовой пояс календарь не хранит: их называет запрос
(`context` ответа приложения), а без него — язык страницы и пояс человека.

## Запрос и ответ

Запрос `query.change` называет видимые дни и контекст:

```js
query.window   // {range: ['2026-10-26', '2026-12-07'], date_field: 'start', end_field: 'end'}
query.context  // {timeZone: 'Europe/Moscow', weekStart: 1, locale: 'ru'}
```

Приложение отвечает записями этих дней (до 1000; больше — `truncated: true`)
и правилами поля даты в `rules`: `past`, `sunday` … `saturday`, `weekdays`,
`min`, `max`, `dates`, каждое со своей причиной `reason`. Записи без даты —
отдельный запрос с `query.window.undated`.

Перенос и растягивание — `record.set` с `patch` полей даты и `revision`.
Пока приложение не ответило, событие бледнее; отказ (`refused` с `message`)
возвращает событие на место, а причину календарь показывает сообщением и
произносит для экранного диктора. Запись с `can: {update: false, reason}`
не переносится.

## Клавиатура

Сетка — одна остановка Tab. Стрелки — день и неделя, Home и End — начало и
конец недели, PageUp и PageDown — период, с Shift — год, T — сегодня. Enter
входит в события дня, Enter на событии открывает запись, Shift+F10 — меню
события (недоступные пункты — с причиной). Ctrl+Shift+стрелки переносят
событие на день или на шаг времени; каждый перенос произносится.

## Параметры

Справочник собран из манифеста компонента в сборке-кандидате набора (`simai/ui-view@987303a5e450`) и обновляется вместе с выпуском. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`.

| | |
|:---|:---|
| Тег | `<sf-view-calendar>` |
| Назначение | Календарь набора представлений: месяц, неделя, день и список; записи стоят в днях своего поля даты, перенос или растягивание — изменение полей даты, которое подтверждает хост. sf-view с layout="calendar" рисует его над окном дат. |
| Контракт | `smart.view-calendar`, версия `1.1.2` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `size` — `string`, по умолчанию `1/2`, значения: `1/2`, `1`. Ступень размера панели, номеров дней, «+», «+N» и строк списка.
- `title-field` — `string`, по умолчанию `title`. Ключ записи, из которого берётся название события (иначе title, name, id).
- `mode` — `string`, по умолчанию пусто, значения: `month`, `week`, `day`, `list`. Показанный режим (иначе mode из layouts.calendar, иначе месяц). На телефоне неделя — три дня, а дня нет.
- `date` — `string`, по умолчанию пусто. День показанного периода, гггг-мм-дд (иначе сегодня в часовом поясе запроса).
- `time-zone` — `string`, по умолчанию пусто. Часовой пояс запроса (context.timeZone): даты и время показываются и записываются в нём; пусто — пояс человека (браузера).
- `week-start` — `integer`. Первый день недели запроса (context.weekStart): 0 или 7 — воскресенье, до 6 — суббота; без него — по языку страницы (для ru понедельник). В виде не хранится.
- `locale` — `string`, по умолчанию пусто. Язык названий месяцев и дней (Intl); пусто — язык страницы.
- `now` — `string`, по умолчанию пусто. «Сейчас» для страницы, которая показывает один момент (гггг-мм-ддTчч:мм): сегодня и линия текущего времени; пусто — часы.
- `selectable` — `boolean`, по умолчанию `true`. Строки режима «Список» несут флажок выбора; пробел отмечает строку.
- `creatable` — `boolean`, по умолчанию `false`. «+» в дне (при наведении и фокусе, на касании всегда): событие создания с датой.
- `movable` — `boolean`, по умолчанию `true`. Перенос и растягивание доступны; false отказывает в каждом с «Нет права менять».
- `truncated` — `boolean`, по умолчанию `false`. Хост отдал только первые 1000 записей периода: «Показаны не все — сузьте фильтр».
- `undated-total` — `integer`. Сколько записей без даты под фильтром (число на «Без даты N»); иначе длина списка без даты.
- `undated-open` — `boolean`, по умолчанию `false`. Колонка «Без даты» открыта (представление хранит это через событие сохранения).
- `current` — `string`, по умолчанию пусто. Запись, открытая в карточке: её событие отмечено.
- `aria-label` — `string`, по умолчанию пусто.
- `records` — `array`, по умолчанию `[]`. Записи дней на экране (окно {range}), до 1000; у каждой id, revision, поля даты и can {update, reason}, где хост ограничивает.
- `undated` — `array`, по умолчанию `[]`. Записи без даты (окно запроса {undated}) для колонки «Без даты».
- `fields` — `array`, по умолчанию `[]`. Описания полей (columns у sf-view): поля даты (поле date — на весь день, datetime — со временем; timeZone — пояс источника), варианты поля цвета, поля «Кратко».
- `options` — `object`, по умолчанию `{}`. layouts.calendar из simai.view-config/1: date_field, end_field, all_day_field, mode, modes, color_field, event_fields (до трёх), per_day (3), hours (["08:00", "20:00"]), slot (30), weekends show|hide, undated button|panel|none, span_days (31, до 366: насколько назад хост ищет событие, начавшееся раньше дней на экране), rules (правила переноса, как настройка rules).
- `rules` — `array`, по умолчанию `[]`. Правила переноса от хоста (describe().rules поля даты и layouts.calendar.rules из simai.view-config/1): [{code, reason}] — past; weekdays {days: дни ISO 1..7, на которые может прийтись начало}; locked {field, in} (запись, у которой поле содержит одно из значений, не переносится); ability {ability} (ответ на каждую запись в can {update, code, reason}); а также sunday..saturday, min {date}, max {date}, dates {dates}. Запрещённый день тускнеет с причиной, пока событие удерживают; правило без причины и отказ хоста с кодом storage_calendar_update_* (past, weekday, locked, denied, end_before_start, too_long, patch_invalid) называются словами языкового пакета. Остальные коды — слова сервера.
- `actions` — `array`, по умолчанию `[]`. Действия хоста над выбранным в режиме «Список», после «Перенести на…».
- `selected` — `array`, по умолчанию `[]`. Идентификаторы, отмеченные в режиме «Список».

## События

События приходят на сам элемент и всплывают.

- `sf-view-calendar-move` — `detail`: `{ id, patch: object, from: object, revision: string|null, how: string }`. Событие перенесено или растянуто (перетаскивание, касание, клавиши, меню, «Перенести на…», из «Без даты» или туда): patch содержит поля даты в их собственном виде; показывается сразу и бледным, пока хост не ответит settleMove. Отмена события — отказ сразу.
- `sf-view-calendar-open` — `detail`: `{ id }`. Событие нажато или выбрано «Открыть» (словарь open): хост открывает карточку записи (sf-view-properties рядом со списком).
- `sf-view-calendar-create` — `detail`: `{ date: string, time?: string, field: string }`. «+» в дне: хост открывает новую запись с этой датой (и временем).
- `sf-view-calendar-range` — `detail`: `{ from: string, to: string, mode: string, window: object, context: object }`. Дни на экране изменились (период, режим, телефон): хост отвечает записями окна window.range [from, to).
- `sf-view-calendar-select` — `detail`: `{ ids: array }`. Отметка изменилась (слово select).
- `sf-view-calendar-save` — `detail`: `{ mode: string, undated_open: boolean }`. Изменился режим или колонка «Без даты»: сохранить в виде (mode в layouts.calendar, личный).
- `sf-view-calendar-apply` — `detail`: `{ action, ids: array, scope: string }`. Действие приложения, выбранное для отмеченных на панели действий.

## Методы

- `settleMove(args: object)` — возвращает `object`. Ответ хоста на перенос: {answer: applied, record?} оставляет его; refused или conflict ({reason, message}) возвращает событие на место и называет причину.
- `setMode(args: object)` — возвращает `boolean`. Показывает режим (month, week, day, list).
- `goTo(args: object)` — возвращает `boolean`. Показывает период вокруг дня (гггг-мм-дд).
- `focusRecord(args: object)` — возвращает `boolean`. Переводит фокус на событие записи (закрытие карточки записи возвращает его сюда).

## Доступность

- Роль: `region`.
- Доступное имя: даёт сам компонент.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Область с названием из aria-label (иначе «Календарь»); сначала кнопки панели, затем одна остановка Tab на сетке с клавишами сетки дат W3C внутри; вежливая живая область называет каждый перенос и отказ; после подтверждённого переноса фокус остаётся на событии.
