# Справочник сотрудников

Справочник компании из одной умной таблицы: 24 сотрудника, поиск по имени,
должности и отделу, сортировка по любой колонке, настройка колонок. На узком
экране таблица сама становится списком: имя и два поля с наибольшим
приоритетом.

## Из чего собран

| Часть экрана | Компонент |
|:---|:---|
| таблица, поиск, сортировка, колонки | `sf-view-table` с `layout="auto"` |
| отдел и формат работы | ячейки типа «выбор» — цветные метки |
| дата приёма | ячейка типа «дата» |
