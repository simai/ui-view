# Заказы интернет-магазина

Рабочий экран менеджера магазина, собранный только из компонентов набора и
SIMAI Framework: список из 48 заказов с поиском, сортировкой и страницами,
фильтр по состоянию, действие «Отгрузить» у новых и собираемых заказов и
карточка открытого заказа рядом со списком.

## Экран

Откройте заказ — справа появится его карточка. Отгрузите заказ из меню
строки — его состояние сменится в строке и в карточке.

:::example {id="demos/orders" label="Заказы" fullscreen=true}
:::

## Из чего собран

| Часть экрана | Компонент |
|:---|:---|
| список заказов, поиск, сортировка, страницы | `sf-view` с `sf-view-table` и `sf-pagination` |
| карточка заказа | `sf-view-properties` |
| фильтр по состоянию | кнопки SIMAI Framework |

Данные отдаёт «приложение» примера: массив заказов и функция `raise`,
которая отвечает на намерения представления и карточки. Настоящая страница
отвечает на те же намерения со своего сервера.
