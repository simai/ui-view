# Файл

:badge[file]{variant=main scheme=on-surface size=1}

Файл: документ или изображение. Сам файл загружает приложение, в записи — ссылка на него.

Шаблоны этого типа. Шаблон выбирают в описании поля, он меняет только рисунок — данные и то, что уходит на сервер, те же; переключатель в примере показывает каждый.

| Шаблон | `template` | Что меняет |
|:---|:---|:---|
| Загрузка файла (по умолчанию) | `upload` | рисует все четыре места |
| Изображение | `image` | Показ, Кратко, Правка: превью изображения; в правке — поле изображения |
| Карточка изображения | `image_card` | Показ, Кратко: изображение крупной карточкой |
| Список изображений | `image_list` | Показ, Кратко: картинки столбцом с именами; кратко — миниатюра и «+N» |

SIMAI Framework, над которым собран этот сайт, читает выбор шаблона из ключа `variant`: «Изображение» — `variant: "image"`, «Карточка изображения» — `variant: "image-card"`, «Список изображений» — `variant: "image-list"`.

## Значение и сервер

| | |
|:---|:---|
| Значение | `{label, mime, href, size}`; с `multiple` — список таких объектов |
| Пустое | `null` |
| Из правки | оставшийся или загруженный файл; загрузку делает приложение запросом `field.upload` |
| Из фильтра | вид файла: `{operator: "in", values: ["image"]}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "photo",
  "label": "Фотография",
  "propertyType": "file",
  "accept": "image/*",
  "uploadText": "Перетащите файл или выберите",
  "uploadHint": "SVG, PNG или JPG, до 10 МБ"
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `accept` | любые | Правка | какие файлы принимать: `.pdf,.docx`, `image/*` |
| `multiple` | нет | все | несколько файлов; задаётся при создании поля |
| `uploadText`, `uploadHint` | слова страницы | Правка | тексты зоны загрузки |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `file@1` |
| Битрикс | свойство «Файл» (`file`) |
