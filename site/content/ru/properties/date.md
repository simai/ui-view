# Дата

:badge[date]{variant=main scheme=on-surface size=1}

Один день: дата рождения, срок, день отгрузки.

Шаблон у типа один — «Поле даты с календарём» (`datepicker`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка `"2026-11-19"` |
| Пустое | `null` |
| Из правки | строка даты; у значения со временем — новый день с прежним временем |
| Из фильтра | `{operator: "between", value: ["2026-11-01", "2026-11-30"]}` и готовые периоды |

Описание поля, которое передаёт приложение:

```json
{"key":"due_date","label":"Срок оплаты","propertyType":"date"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `min`, `max` | нет | Правка | границы дня, дата ISO |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `date@1` |
| Битрикс | свойство «Дата/время» без времени |
