# Процент

:badge[percent]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Процент: скидка, ставка, доля. Значение «12.5» — это 12,5 %, а не доля.

Шаблон у типа один — «Поле числа» (`input`): он рисует все четыре места.

:::example {id="properties/percent" label="Процент: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | десятичная строка: `"12.5"` — это 12,5 %, а не доля |
| Пустое | `null` |
| Из правки | десятичная строка |
| Из фильтра | как число: `{operator: "gte", value: "10"}` |

Описание поля, которое передаёт приложение:

```json
{"key":"discount","label":"Скидка","propertyType":"percent"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `min`, `max` | 0 и 100 | Правка | границы |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `percent@1` |
| Битрикс | нет |
