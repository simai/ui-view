# Процент

:badge[percent]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Процент: скидка, ставка, доля. Значение «12.5» — это 12,5 %, а не доля.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

:::

## Формат и настройки

| | |
|:---|:---|
| Значение | десятичная строка: `"12.5"` — это 12,5 %, а не доля |
| В карточке | «12,5 %» |
| В ячейке таблицы и фильтре | как число |
| В правке | поле со знаком % |
| Пустое | `null` |

| Настройка | Что задаёт |
|:---|:---|
| `min`, `max` | границы; без них от 0 до 100 |
| `required`, `readonly` | обязательное поле и поле только для чтения |
