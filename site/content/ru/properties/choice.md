# Одно из списка

:badge[choice]{variant=main scheme=on-surface size=1}

Один вариант из короткого списка: статус, приоритет, тип. Хранится код варианта.

Шаблоны этого типа. Шаблон выбирают в описании поля, он меняет только рисунок — данные и то, что уходит на сервер, те же; переключатель в примере показывает каждый.

| Шаблон | `template` | Что меняет |
|:---|:---|:---|
| Выпадающий список (по умолчанию) | `dropdown` | рисует все четыре места |
| Кнопки | `buttons` | Правка: кнопка на вариант; повторное нажатие очищает необязательное поле |

SIMAI Framework, над которым собран этот сайт, читает выбор шаблона из ключа `variant`: «Кнопки» — `variant: "buttons"`.

## Значение и сервер

| | |
|:---|:---|
| Значение | код варианта `"active"` |
| Пустое | `null` |
| Из правки | код выбранного варианта |
| Из фильтра | `{operator: "in", values: […]}` — любой из выбранных |

Описание поля, которое передаёт приложение:

```json
{
  "key": "status",
  "label": "Статус",
  "propertyType": "choice",
  "options": [
    {"value":"draft","label":"Черновик","scheme":"neutral"},
    {"value":"review","label":"На проверке","scheme":"warning"},
    {"value":"active","label":"Действует","scheme":"success"},
    {"value":"signing","label":"Ждёт подписи второй стороны","scheme":"info"}
  ]
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `options` | нет | все | варианты `{value, label, scheme}`; `scheme` — цвет метки |
| `badgeAppearance` | `tonal` | Показ, Кратко | вид метки: `tonal` или `outline` |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `choice@1` |
| Битрикс | свойство «Список» (`list`) |
