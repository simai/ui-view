# Пароль

:badge[password]{variant=main scheme=on-surface size=1}

Пароль, который никогда не приходит на страницу: приложение сообщает только, задан он или нет.

Шаблон у типа один — «Скрытое поле» (`input`): он рисует все четыре места.

:::example {id="properties/password" label="Пароль: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | сам пароль не приходит никогда: `{set: true}` — задан, `{set: false}` — не задан |
| Пустое | `null` — как «не задан» |
| Из правки | набранный текст, один раз; поле, которого не касались, ничего не передаёт и заданный пароль не стирает |
| Из фильтра | по паролю не ищут; задан он или нет — решает приложение |

Описание поля, которое передаёт приложение:

```json
{"key":"secret","label":"Пароль хранилища","propertyType":"password","placeholder":"Новый пароль"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `required` | нет | Правка | обязательное поле; если пароль уже задан, не действует |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | нет: секреты хранит пакет `secret` |
| Битрикс | нет |
