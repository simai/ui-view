# Целое число

:badge[integer]{variant=main scheme=on-surface size=1}

Целое число: количество, номер, остаток на складе.

Шаблоны этого типа. Шаблон выбирают в описании поля, он меняет только рисунок — данные и то, что уходит на сервер, те же; переключатель в примере показывает каждый.

| Шаблон | `template` | Что меняет |
|:---|:---|:---|
| Поле числа (по умолчанию) | `input` | рисует все четыре места |
| Кнопки «−» и «+» | `stepper` | Правка: поле количества: кнопки «−» и «+» и стрелки клавиатуры, шаг `step` |

SIMAI Framework, над которым собран этот сайт, читает выбор шаблона из ключа `variant`: «Кнопки «−» и «+»» — `variant: "stepper"`.

## Значение и сервер

| | |
|:---|:---|
| Значение | целое число `128` |
| Пустое | `null` |
| Из правки | целое число; очищенное поле — `null` |
| Из фильтра | `{operator: "between", value: [10, 500]}` и другие сравнения |

Описание поля, которое передаёт приложение:

```json
{
  "key": "stock",
  "label": "Остаток",
  "propertyType": "integer",
  "unit": "шт.",
  "min": 0,
  "max": 100000,
  "step": 1
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `unit` | нет | Показ, Кратко | единица после числа: `шт.`, `кг` |
| `min`, `max`, `step` | нет | Правка | границы и шаг ввода |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `integer@1` |
| Битрикс | свойство «Число» (`number`), целое |
