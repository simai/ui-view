# Да или нет

:badge[boolean]{variant=main scheme=on-surface size=1}

Признак «да» или «нет»: подписан, активен, работает удалённо. Слова для обоих значений задаёт приложение.

Шаблон у типа один — «Переключатель» (`switch`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `true` или `false` |
| Пустое | `null` — «не задано» |
| Из правки | `true` или `false`; у необязательного поля ещё `null` |
| Из фильтра | `{operator: "eq", value: true}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "remote",
  "label": "Работает удалённо",
  "propertyType": "boolean",
  "trueText": "Удалённо",
  "falseText": "В офисе"
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `trueText`, `falseText` | «Да», «Нет» | Показ, Кратко, Правка | свои слова вместо «Да» и «Нет» |
| `required` | нет | Правка | переключатель вместо пары кнопок «Да» и «Нет»; значение всегда `true` или `false` |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `boolean@1` |
| Битрикс | свойство «Флажок» (`checkbox`) |
