# Составное

:badge[compound]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Несколько частей одного значения: адрес из города, улицы и индекса. Каждая часть рисуется своим типом.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

| | |
|:---|:---|
| Значение | один объект: ключ — часть, значение — в формате её типа; пустая часть — отсутствие ключа |
| В карточке | части по порядку |
| В ячейке таблицы и фильтре | текст частей |
| В правке | поле на каждую часть, своим типом |
| Пустое | `null` |

| Настройка | Что задаёт |
|:---|:---|
| `parts` | список описаний полей — частей значения |
| `required`, `readonly` | обязательное поле и поле только для чтения |
