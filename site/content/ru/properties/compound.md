# Составное

:badge[compound]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Несколько частей одного значения: адрес из города, улицы и индекса. Каждая часть рисуется своим типом.

Шаблон у типа один — «Части» (`parts`): он рисует все четыре места.

:::example {id="properties/compound" label="Составное: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | один объект: ключ — часть, значение — в формате её типа |
| Пустое | `null`; пустая часть — нет ключа |
| Из правки | тот же объект |
| Из фильтра | поиск по тексту частей |

Описание поля, которое передаёт приложение:

```json
{
  "key": "address",
  "label": "Адрес",
  "propertyType": "compound",
  "parts": [
    {"key":"city","label":"Город","propertyType":"string"},
    {"key":"street","label":"Улица и дом","propertyType":"string"},
    {"key":"zip","label":"Индекс","propertyType":"string"}
  ]
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `parts` | нет | все | описания полей — частей значения |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | нет (составное не переносится) |
| Битрикс | свойство «Комплексное» (`complex`) |
