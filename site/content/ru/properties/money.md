# Сумма

:badge[money]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Сумма и её валюта: бюджет, цена, взнос. Число — десятичная строка, без округления.

Шаблон у типа один — «Сумма с валютой» (`money_input`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{amount: "4990.50", currency: "RUB"}`: сумма десятичной строкой и код ISO 4217 |
| Пустое | `null` |
| Из правки | тот же объект; лишние знаки после запятой не округляются, а останавливают сохранение |
| Из фильтра | как число: `{operator: "between", value: ["1000", "5000"]}` |

Описание поля, которое передаёт приложение:

```json
{"key":"budget","label":"Бюджет","propertyType":"money"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `currency` | нет | Показ, Правка | валюта поля: выбирать её не нужно, простая сумма тоже читается |
| `min`, `max` | нет | Правка | границы суммы |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `money@1` |
| Битрикс | нет |
