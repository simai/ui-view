# Сумма

:badge[money]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Сумма и её валюта: бюджет, цена, взнос. Число — десятичная строка, без округления.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

| | |
|:---|:---|
| Значение | `{"amount": "1500.50", "currency": "RUB"}`: сумма десятичной строкой и код валюты ISO 4217 |
| В карточке | «1 500,50 ₽» |
| В ячейке таблицы и фильтре | как число: фильтр сравнивает сумму |
| В правке | поле суммы и выбор валюты; с `currency` валюта задана и стоит в поле |
| Пустое | `null` |

| Настройка | Что задаёт |
|:---|:---|
| `currency` | валюта поля: тогда выбирать её не нужно, и простая сумма тоже читается |
| `min`, `max` | границы суммы |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Знаков после запятой столько, сколько у валюты (у рубля 2, у иены 0):
лишние знаки не округляются, а останавливают сохранение, и поле говорит,
что не так.
