# Пользователь

:badge[user]{variant=main scheme=on-surface size=1}

Человек: ответственный, автор, исполнитель. Имя и буквы для аватара приложение передаёт готовыми.

Шаблон у типа один — «Поиск сотрудника» (`reference_picker`): он рисует все четыре места.

:::example {id="properties/user" label="Пользователь: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{value, label, avatarText}`: идентификатор, имя, буквы для аватара |
| Пустое | `null` |
| Из правки | выбранный `{value, label}` или `null` |
| Из фильтра | `{operator: "in", values: […]}` — любой из выбранных |

Описание поля, которое передаёт приложение:

```json
{
  "key": "owner",
  "label": "Ответственный",
  "propertyType": "user",
  "placeholder": "Выберите сотрудника",
  "searchPlaceholder": "Имя сотрудника"
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка пустого поля |
| `searchPlaceholder` | нет | Правка | подсказка поиска; кандидатов даёт приложение запросом `field.options` |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `user@1` |
| Битрикс | свойство «Привязка к сотруднику» |
