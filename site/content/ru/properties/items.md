# Строки

:badge[items]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Строки по колонкам: позиции счёта, этапы, состав. Ячейка может считаться из других, колонка — давать итог.

Шаблон у типа один — «Строки» (`rows`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | список строк; строка — объект по ключам колонок, пустая ячейка — нет ключа |
| Пустое | `null` |
| Из правки | список строк; вычисленное — подсказка, окончательное считает приложение |
| Из фильтра | число строк, как число |

Описание поля, которое передаёт приложение:

```json
{
  "key": "lines",
  "label": "Позиции",
  "propertyType": "items",
  "minRows": 1,
  "maxRows": 20,
  "columns": [
    {"key":"name","label":"Наименование","type":"string","required":true},
    {"key":"qty","label":"Кол-во","type":"number"},
    {"key":"price","label":"Цена","type":"money","settings":{"currency":"RUB"}},
    {"key":"sum","label":"Сумма","type":"money","compute":{"op":"multiply","of":["qty","price"]},"total":"sum"}
  ]
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `columns` | нет | все | колонки `{key, label, type, compute, total}` |
| `minRows`, `maxRows` | нет | Правка | сколько строк можно оставить и добавить |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `items@1` |
| Битрикс | нет |
