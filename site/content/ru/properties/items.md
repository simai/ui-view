# Строки

:badge[items]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Строки по колонкам: позиции счёта, этапы, состав. Ячейка может считаться из других, колонка — давать итог.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

| | |
|:---|:---|
| Значение | список строк; пустая ячейка — отсутствие ключа |
| В карточке | таблица строк с итогами |
| В ячейке таблицы и фильтре | число строк |
| В правке | редактор строк: добавить, передвинуть, удалить; на телефоне и в половине ширины каждая строка — карточка |
| Пустое | `null` |

| Настройка | Что задаёт |
|:---|:---|
| `columns` | колонки `{key, label, type, settings, required, compute, total}`; типы ячеек: строка, текст, целое, число, процент, сумма, выбор, дата, да или нет |
| `compute` | `{op: "multiply", of: [ключи]}` — ячейка только для чтения, считается из других и пишется последней в строке |
| `total` | `"sum"` — сумма колонки под таблицей |
| `minRows`, `maxRows` | сколько строк можно оставить и добавить |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Вычисленное значение — подсказка человеку; окончательное считает
приложение.

```json
{"key": "lines", "label": "Позиции", "propertyType": "items", "minRows": 1, "maxRows": 20,
 "columns": [
   {"key": "name", "label": "Наименование", "type": "string", "required": true},
   {"key": "qty", "label": "Кол-во", "type": "number"},
   {"key": "price", "label": "Цена", "type": "money", "settings": {"currency": "RUB"}},
   {"key": "sum", "label": "Сумма", "type": "money", "compute": {"op": "multiply", "of": ["qty", "price"]}, "total": "sum"}]}
```
