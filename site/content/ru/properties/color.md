# Цвет

:badge[color]{variant=main scheme=on-surface size=1}

Цвет: метки, бренда, категории. Приложение может предложить свои образцы.

Шаблон у типа один — «Выбор цвета» (`color_picker`): он рисует все четыре места.

:::example {id="properties/color" label="Цвет: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка `"#0f766e"` |
| Пустое | `null` |
| Из правки | строка цвета |
| Из фильтра | цвета палитры: `{operator: "in", values: ["#0f766e"]}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "tag",
  "label": "Цвет метки",
  "propertyType": "color",
  "swatches": ["#1d4ed8","#0f766e","#b45309","#be123c","#6d28d9","#334155"]
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `swatches` | палитра Framework | Правка, Фильтр | образцы в правке и варианты в фильтре |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `color@1` |
| Битрикс | свойство «Цвет» (`color`) |
