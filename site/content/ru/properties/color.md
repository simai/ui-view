# Цвет

:badge[color]{variant=main scheme=on-surface size=1}

Цвет: метки, бренда, категории. Приложение может предложить свои образцы.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

:::

## Формат и настройки

| | |
|:---|:---|
| Значение | строка цвета, например `#1d4ed8` |
| В таблице и карточке | образец цвета и его код |
| В правке | образец, код, палитра `swatches` и кнопка сброса; в половине строки карточки образцы переносятся внутри поля |
| Что уходит в сохранение | строка цвета |

| Настройка | Что задаёт |
|:---|:---|
| `swatches` | палитра: образцы в правке и варианты в фильтре |
| `inheritedValue` | цвет, унаследованный от темы, пока свой не выбран |
| `required` | запрещает очистку |
| `readonly` | поле только для чтения |
