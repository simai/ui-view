# Адрес в интернете

:badge[url]{variant=main scheme=on-surface size=1}

Адрес страницы в интернете: полный адрес http или https, не длиннее 2048 байт, без логина и пароля в нём.

Шаблон у типа один — «Поле адреса» (`input`): он рисует все четыре места.

:::example {id="properties/url" label="Адрес в интернете: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка — полный адрес http или https, до 2048 байт |
| Пустое | `null` |
| Из правки | адрес как в поле; адрес без http(s) или с логином внутри не сохраняется |
| Из фильтра | `{operator: "contains", value: "simai"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "site",
  "label": "Сайт компании",
  "propertyType": "url",
  "placeholder": "https://",
  "filter": {"operators":["contains"],"defaultOperator":"contains"}
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `url@1` |
| Битрикс | свойство «Строка» (`string`) |
