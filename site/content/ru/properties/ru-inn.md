# ИНН

:badge[ru.inn]{variant=main scheme=on-surface size=1}

ИНН: 10 цифр у организации или 12 у человека и предпринимателя; контрольные цифры проверяются при вводе.

Шаблон у типа один — «Поле ИНН» (`input`): он рисует все четыре места.

:::example {id="properties/ru-inn" label="ИНН: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка из 10 или 12 цифр |
| Пустое | `null` |
| Из правки | цифры; с неверными контрольными цифрами значение не сохраняется |
| Из фильтра | `{operator: "contains", value: "7707"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "inn",
  "label": "ИНН",
  "propertyType": "ru.inn",
  "holder": "any",
  "filter": {"operators":["contains"],"defaultOperator":"contains"}
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `holder` | `any` | Правка | чей ИНН: `any`, `organization` (10 цифр) или `person` (12); задаётся при создании поля |
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `ru.inn@1` |
| Битрикс | нет |
