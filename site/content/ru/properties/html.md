# Форматированный текст

:badge[html]{variant=main scheme=on-surface size=1}

Текст с оформлением: абзацы, заголовки, жирный и курсив, ссылки, списки и цитаты.

Шаблон у типа один — «Редактор» (`editor`): он рисует все четыре места.

:::example {id="properties/html" label="Форматированный текст: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка HTML из набора `sf-input-rich`; при показе очищается |
| Пустое | `null` |
| Из правки | очищенная строка HTML |
| Из фильтра | поиск по тексту без разметки: `{operator: "contains", value: "дизайн"}` |

Описание поля, которое передаёт приложение:

```json
{"key":"notes","label":"Описание с оформлением","propertyType":"html"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `html@1` |
| Битрикс | свойство «HTML» (`html`) |
