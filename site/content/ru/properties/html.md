# Форматированный текст

:badge[html]{variant=main scheme=on-surface size=1}

Текст с оформлением: абзацы, заголовки, жирный и курсив, ссылки, списки и цитаты.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

| | |
|:---|:---|
| Значение | строка HTML из того подмножества, которое понимает `sf-input-rich` |
| В карточке | оформленный текст, очищенный по правилам `sf-input-rich` |
| В правке | редактор `sf-input-rich` с панелью оформления |
| В таблице | текст без разметки в одну строку |

Настройки: `placeholder`, `required`, `readonly`. Фильтр по такому полю ищет
как по тексту.
