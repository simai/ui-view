# Текст

:badge[text]{variant=main scheme=on-surface size=1}

Многострочный текст: описание, комментарий, заметка. Переводы строк сохраняются.

Шаблон у типа один — «Многострочное поле» (`textarea`): он рисует все четыре места.

:::example {id="properties/text" label="Текст: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка; переводы строк — `\n` |
| Пустое | `null` |
| Из правки | строка как в поле |
| Из фильтра | `{operator: "contains", value: "кабинет"}` |

Описание поля, которое передаёт приложение:

```json
{"key":"about","label":"Описание","propertyType":"text","placeholder":"Пара предложений о проекте"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `text@1` |
| Битрикс | свойство «Текст» (`text`) |
