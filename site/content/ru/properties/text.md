# Текст

:badge[text]{variant=main scheme=on-surface size=1}

Многострочный текст: описание, комментарий, заметка. Переводы строк сохраняются.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

:::

## Формат и настройки

| | |
|:---|:---|
| Значение | строка; переводы строк сохраняются |
| В таблице | текст в одну строку с обрезкой; целиком — во всплывающей подсказке |
| В карточке | текст с переводами строк |
| В правке | многострочное поле |

Настройки: `placeholder`, `required`, `readonly`.
