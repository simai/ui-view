# Несколько из списка

:badge[choices]{variant=main scheme=on-surface size=1}

Несколько вариантов из списка: навыки, теги, дни приёма. Хранится список кодов.

Шаблоны этого типа. Шаблон выбирают в описании поля, он меняет только рисунок — данные и то, что уходит на сервер, те же; переключатель в примере показывает каждый.

| Шаблон | `template` | Что меняет |
|:---|:---|:---|
| Выпадающий список (по умолчанию) | `dropdown` | рисует все четыре места |
| Флажки | `checklist` | Правка: флажки при любой длине списка |
| Значки | `badges` | Показ, Кратко: метки в цветах вариантов |

SIMAI Framework, над которым собран этот сайт, читает выбор шаблона из ключа `variant`: «Флажки» — `variant: "checklist"`, «Значки» — `variant: "badges"`.

## Значение и сервер

| | |
|:---|:---|
| Значение | список кодов `["js", "sql"]` |
| Пустое | `null` или `[]` |
| Из правки | список кодов в порядке вариантов |
| Из фильтра | `{operator: "in", values: […]}` — любой из выбранных |

Описание поля, которое передаёт приложение:

```json
{
  "key": "skills",
  "label": "Навыки",
  "propertyType": "choices",
  "options": [
    {"value":"js","label":"JavaScript","scheme":"primary"},
    {"value":"php","label":"PHP","scheme":"primary"},
    {"value":"sql","label":"SQL","scheme":"success"},
    {"value":"ux","label":"UX","scheme":"warning"},
    {"value":"qa","label":"Тестирование","scheme":"neutral"}
  ]
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `options` | нет | все | варианты `{value, label, scheme}` |
| `badgeAppearance` | `tonal` | Показ, Кратко | вид меток |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `choices@1` |
| Битрикс | свойство «Список», несколько значений |
