# Телефон

:badge[phone]{variant=main scheme=on-surface size=1}

Номер телефона. Хранится в одном виде для всех стран — E.164: «+», код страны и номер, без пробелов; добавочный — после «;ext=».

SIMAI Framework, над которым собран этот сайт, описывает это свойство как `string` с `variant: "phone"`; так его и рисует пример.

Шаблон у типа один — «Телефон с кодом страны» (`phone_input`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка E.164 `"+79161234567"`: «+», код страны и номер; добавочный — после `;ext=` |
| Пустое | `null` |
| Из правки | номер из поля с кодом страны — см. строку «Сервер получит» в правке |
| Из фильтра | цифры номера: `{operator: "contains", value: "916"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "phone",
  "label": "Телефон",
  "propertyType": "phone",
  "filter": {"operators":["contains"],"defaultOperator":"contains"}
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `defaultCountry` | страна страницы | Правка | страна, с которой открывается пустое поле |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `phone@1` — E.164, короткая колонка |
| Битрикс | свойство «Телефон» (`phone`) |
