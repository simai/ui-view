# Ссылка с текстом

:badge[link]{variant=main scheme=on-surface size=1}

Ссылка с текстом: адрес — полный http или https, путь от корня сайта или якорь «#…», — и слова, которые видит человек.

Шаблон у типа один — «Ссылка» (`link`): он рисует все четыре места.

:::example {id="properties/link" label="Ссылка с текстом: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{href, text}`: `href` — http(s), путь от корня сайта или якорь; `text` можно не задавать |
| Пустое | `null` |
| Из правки | тот же объект |
| Из фильтра | поиск по тексту и адресу: `{operator: "contains", value: "docs"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "docs",
  "label": "Документация",
  "propertyType": "link",
  "filter": {"operators":["contains"],"defaultOperator":"contains"}
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `link@1` |
| Битрикс | нет |
