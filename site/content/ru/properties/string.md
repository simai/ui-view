# Строка

:badge[string]{variant=main scheme=on-surface size=1}

Короткий текст в одну строку: название, имя, код. Хранится строкой так, как его ввели.

Шаблон у типа один — «Поле ввода» (`input`): он рисует все четыре места.

## Значение и сервер

| | |
|:---|:---|
| Значение | строка `"Портал клиента"` |
| Пустое | `null`; у поля с маской и `nullable: false` — `""` |
| Из правки | строка как в поле; с маской — вместе с постоянными знаками, незаконченная не уходит |
| Из фильтра | `{operator: "contains", value: "портал"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "title",
  "label": "Название проекта",
  "propertyType": "string",
  "placeholder": "Например, «Портал клиента»",
  "filter": {"operators":["contains"],"defaultOperator":"contains"}
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка в пустом поле |
| `mask` | нет | Правка | маска ввода по правилам масок SIMAI Framework; значение — текст, как он показан |
| `nullable` | `true` | Правка | `false` — очищенное поле с маской передаёт `""`, а не `null` |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `string@2` — строка, длина в символах |
| Битрикс | свойство «Строка» (`string`) |
