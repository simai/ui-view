# Число

:badge[number]{variant=main scheme=on-surface size=1}

Число с заданной точностью: цена, вес, готовность.

Шаблоны этого типа. Шаблон выбирают в описании поля, он меняет только рисунок — данные и то, что уходит на сервер, те же; переключатель в примере показывает каждый.

| Шаблон | `template` | Что меняет |
|:---|:---|:---|
| Поле числа (по умолчанию) | `input` | рисует все четыре места |
| Кнопки «−» и «+» | `stepper` | Правка: поле количества: кнопки «−» и «+» и стрелки клавиатуры, шаг `step` |
| Шкала | `scale` | Показ, Кратко: шкала уровня от 0 до 100 |
| Заполненность | `meter` | Показ, Кратко: полоса заполненности лимита от 0 до 100 |

SIMAI Framework, над которым собран этот сайт, читает выбор шаблона из ключа `variant`: «Кнопки «−» и «+»» — `variant: "stepper"`, «Шкала» — `variant: "scale"`, «Заполненность» — `variant: "meter"`.

## Значение и сервер

| | |
|:---|:---|
| Значение | число `72.5` |
| Пустое | `null` |
| Из правки | число; очищенное поле — `null` |
| Из фильтра | `{operator: "gte", value: 50}` и другие сравнения |

Описание поля, которое передаёт приложение:

```json
{
  "key": "progress",
  "label": "Готовность",
  "propertyType": "number",
  "unit": "%",
  "min": 0,
  "max": 100,
  "step": 0.5,
  "precision": 1
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `precision` | по значению | Показ, Кратко, Правка | знаков после запятой |
| `unit` | нет | Показ, Кратко | единица после числа |
| `min`, `max`, `step` | нет | Правка | границы и шаг; шкала и заполненность — только у поля от 0 до 100 |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `number@1` — десятичная строка |
| Битрикс | свойство «Число» (`number`) |
