# Время

:badge[time]{variant=main scheme=on-surface size=1}

Время суток без даты: начало рабочего дня, время доставки.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

Набор показывает дату на языке страницы: `2026-11-15` в таблице и карточке
читается как «15 нояб. 2026 г.», `2026-11-15T10:30:00` — как
«15 нояб. 2026 г., 10:30», `09:30` — как «09:30». Свой вид даёт приложение
функцией `formatFieldValue` — её ответ главнее
([Формат дат и чисел](/ru/guide/concepts/data/)).

| | |
|:---|:---|
| Значение | время суток `чч:мм`, допустимы секунды и доли: `09:30:00` |
| В правке | поле `sf-input-date` в режиме `time`: строка времени, ввод «09:30» |
| Что уходит в сохранение | `чч:мм`; если приложение хранит секунды — `чч:мм:00`; та же минута возвращается без изменений; очищенное поле — `null` |

| Настройка | Что задаёт |
|:---|:---|
| `min`, `max` | границы в виде `чч:мм` |
| `step` | шаг минут, от 1 до 60 |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Фильтр по времени ищет как по тексту.
