# Время

:badge[time]{variant=main scheme=on-surface size=1}

Время суток без даты: начало рабочего дня, время доставки.

Шаблон у типа один — «Поле времени» (`timepicker`): он рисует все четыре места.

:::example {id="properties/time" label="Время: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка `"09:00"` |
| Пустое | `null` |
| Из правки | `чч:мм`; если приложение хранит секунды — `чч:мм:00` |
| Из фильтра | поиск по тексту: `{operator: "contains", value: "09"}` |

Описание поля, которое передаёт приложение:

```json
{
  "key": "workday",
  "label": "Начало рабочего дня",
  "propertyType": "time",
  "min": "07:00",
  "max": "12:00",
  "step": 30
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `min`, `max` | нет | Правка | границы `чч:мм` |
| `step` | 1 | Правка | шаг минут, от 1 до 60 |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | нет |
| Битрикс | нет |
