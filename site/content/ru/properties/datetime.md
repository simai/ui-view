# Дата и время

:badge[datetime]{variant=main scheme=on-surface size=1}

Момент времени: начало встречи, время заказа. Значение — строка ISO 8601.

## Формат и настройки

Набор показывает дату на языке страницы: `2026-11-15` в таблице и карточке
читается как «15 нояб. 2026 г.», `2026-11-15T10:30:00` — как
«15 нояб. 2026 г., 10:30», `09:30` — как «09:30». Свой вид даёт приложение
функцией `formatFieldValue` — её ответ главнее
([Формат дат и чисел](/ru/guide/concepts/data/)).

| | |
|:---|:---|
| Значение | ISO 8601: `2026-11-15T10:30:00`, с секундами, долями секунды и часовым поясом или без них; одна дата `ГГГГ-ММ-ДД` тоже читается |
| В правке | одно поле `sf-input-date` в режиме `datetime`: календарь со строкой времени, ввод «15.11.2026 10:30» |
| Что уходит в сохранение | строка ISO 8601; `null`, когда оба поля очищены |

| Настройка | Что задаёт |
|:---|:---|
| `min`, `max` | границы: дата или дата со временем в ISO |
| `step` | шаг минут, от 1 до 60 |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Новый день сохраняет прежнее время вместе с секундами и часовым поясом;
новое время записывается с точностью до минуты.

**Незаконченный ввод.** Поле записывает только целое значение: день без
времени в сохранение не уходит, а поле возвращает прежнее значение.
