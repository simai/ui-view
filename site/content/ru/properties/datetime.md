# Дата и время

:badge[datetime]{variant=main scheme=on-surface size=1}

Момент времени: начало встречи, время заказа. Значение — строка ISO 8601.

Шаблон у типа один — «Календарь и время» (`datepicker`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | строка ISO 8601 `"2026-11-19T10:30:00"` |
| Пустое | `null` |
| Из правки | строка ISO 8601; новый день сохраняет прежнее время, день без времени не уходит |
| Из фильтра | `{operator: "between", value: ["2026-11-01", "2026-11-30"]}` и готовые периоды |

Описание поля, которое передаёт приложение:

```json
{"key":"meeting","label":"Начало встречи","propertyType":"datetime","step":15}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `min`, `max` | нет | Правка | границы: дата или дата со временем |
| `step` | 1 | Правка | шаг минут, от 1 до 60 |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `datetime@1` — местное время без пояса |
| Битрикс | свойство «Дата/время» |
