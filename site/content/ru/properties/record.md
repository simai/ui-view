# Запись

:badge[record]{variant=main scheme=on-surface size=1}

Ссылка на другую запись: договор, заказ, проект. Открыть её решает приложение.

Шаблон у типа один — «Выбор записи» (`reference_picker`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{value, label, href}`; `href` — только когда запись можно открыть |
| Пустое | `null` |
| Из правки | выбранный `{value, label}` или `null` |
| Из фильтра | `{operator: "in", values: […]}` — любой из выбранных |

Описание поля, которое передаёт приложение:

```json
{
  "key": "contract",
  "label": "Договор",
  "propertyType": "record",
  "placeholder": "Выберите договор",
  "searchPlaceholder": "Номер договора"
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `placeholder` | нет | Правка | подсказка пустого поля |
| `searchPlaceholder` | нет | Правка | подсказка поиска; кандидатов даёт приложение запросом `field.options` |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `record@1` |
| Битрикс | свойство «Привязка к элементу» |
