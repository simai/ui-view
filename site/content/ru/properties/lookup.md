# Из справочника

:badge[lookup]{variant=main scheme=on-surface size=1}

Значение из справочника, который хранит приложение: страна, город, вид договора. Из значения ничего не открывается.

Шаблон у типа один — «Список справочника» (`source_picker`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{value: "ru", label: "Россия"}` |
| Пустое | `null` |
| Из правки | выбранный `{value, label}` или `null` |
| Из фильтра | `{operator: "in", values: […]}` — любой из выбранных |

Описание поля, которое передаёт приложение:

```json
{
  "key": "country",
  "label": "Страна",
  "propertyType": "lookup",
  "source": "countries",
  "options": [
    {"value":"ru","label":"Россия"},
    {"value":"de","label":"Германия"},
    {"value":"fr","label":"Франция"},
    {"value":"cf","label":"Центральноафриканская Республика"},
    {"value":"jp","label":"Япония"}
  ],
  "placeholder": "Выберите страну"
}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `options` | нет | Правка, Фильтр | короткий справочник целиком |
| `source` | нет | Правка | имя справочника: большой приходит от приложения страницами |
| `multiple` | нет | все | несколько значений; задаётся при создании поля |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `lookup@1` — одно значение |
| Битрикс | нет |
