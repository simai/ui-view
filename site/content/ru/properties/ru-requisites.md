# Реквизиты

:badge[ru.requisites]{variant=main scheme=on-surface size=1} :badge[Тип набора view]{variant=tonal scheme=info size=1}

Реквизиты организации или предпринимателя: ИНН, КПП, ОГРН, БИК и счета. Каждая часть проверяется, и те, что идут вместе, — вместе.

Шаблон у типа один — «Блок реквизитов» (`requisites`): он рисует все четыре места.

:::example {id="properties/ru-requisites" label="Реквизиты: показ, кратко, правка, фильтр" sources=false}
:::

## Значение и сервер

| | |
|:---|:---|
| Значение | `{inn, kpp, ogrn, bik, account, corr_account}` |
| Пустое | `null` |
| Из правки | тот же объект; ошибка в части останавливает сохранение |
| Из фильтра | поиск по тексту реквизитов |

Описание поля, которое передаёт приложение:

```json
{"key":"requisites","label":"Реквизиты","propertyType":"ru.requisites"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `parts` | все шесть | все | какие части есть у поля |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | `ru.requisites@1` |
| Битрикс | нет |
