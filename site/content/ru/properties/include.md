# Код

:badge[include]{variant=main scheme=on-surface size=1}

Фрагмент кода или настроек: JSON, YAML, шаблон. Показывается моноширинным шрифтом.

## Примеры

Те же записи в ячейке таблицы, в фильтре над таблицей, в карточке для чтения и для правки; ниже — состояния: пусто, ошибка, только чтение и телефон.

## Формат и настройки

| | |
|:---|:---|
| Значение | строка |
| В карточке | блок кода моноширинным шрифтом |
| В правке | многострочное поле |
| В таблице | первая строка кода |

| Настройка | Что задаёт |
|:---|:---|
| `language` | язык кода, атрибут `data-language` |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Фильтр по такому полю ищет как по тексту.
