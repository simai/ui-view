# Код

:badge[include]{variant=main scheme=on-surface size=1}

Фрагмент кода или настроек: JSON, YAML, шаблон. Показывается моноширинным шрифтом.

Шаблон у типа один — «Код» (`script`): он рисует все четыре места.

:::

## Значение и сервер

| | |
|:---|:---|
| Значение | текст кода строкой |
| Пустое | `null` |
| Из правки | текст как в поле |
| Из фильтра | поиск по тексту: `{operator: "contains", value: "theme"}` |

Описание поля, которое передаёт приложение:

```json
{"key":"config","label":"Настройки","propertyType":"include","language":"json"}
```

## Настройки

| Настройка | По умолчанию | Где меняет | Что задаёт |
|:---|:---|:---|:---|
| `language` | обычный текст | Показ, Правка | язык кода, атрибут `data-language` |
| `required` | нет | Правка | обязательное поле: отметка у подписи, пустое не сохраняется |
| `readonly` | нет | Правка | поле только для чтения: значение видно, изменить нельзя |

## Где хранится

| Система | Как хранит |
|:---|:---|
| Larena | нет |
| Битрикс | включаемая область (`include`) |
