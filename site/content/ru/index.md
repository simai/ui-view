# SIMAI View

SIMAI View — набор компонентов `view` для SIMAI Framework: всё, чем приложение
показывает данные. Приложение отдаёт записи, а компоненты набора рисуют их
таблицей или списком, ищут, сортируют, разбивают на страницы и показывают
карточку одной записи.

## Что входит в набор

| Компонент | Что делает |
|:---|:---|
| [`sf-view`](components/view/) | представление данных: берёт записи у приложения через порт данных и показывает их с поиском, сортировкой, страницами, сохранёнными видами и деревом |
| [`sf-view-table`](components/view-table/) | умная таблица: типизированные ячейки, колонки, действия над строками; на узком экране — список |
| [`sf-view-properties`](components/view-properties/) | карточка записи: свойства одной записи в группах и разделах, просмотр и правка |

Дальше в набор войдут другие виды тех же данных: канбан, календарь и
диаграмма Ганта. Простой список и простая таблица остаются в бесплатном
SIMAI Framework.

## Лицензия

Набор `view` распространяется по лицензии SIMAI Pro, общей для всех платных
наборов:

- бесплатно для малого бизнеса — PolyForm Small Business 1.0.0;
- бесплатно для некоммерческого использования — PolyForm Noncommercial 1.0.0;
- остальным — коммерческая лицензия SIMAI по запросу.

Автор и правообладатель — Рим Забаров. Сам SIMAI Framework, на котором
построен набор, распространяется по лицензии Apache-2.0.

## Совместимость с SIMAI Framework

| | |
|:---|:---|
| Набор | `view`, версия 1.0.0 |
| Собран и проверен над | выпуском SIMAI Framework `ui-62b1d9b6dc8d` (npm `@simai-studio/ui@5.20261105.1447`) |
| Исходники Framework | `simai/ui-source` `ec2f29dfa5df` |
| Нужен Core | `core.runtime` 1.25.0 или новее |
| Другие наборы | не нужны |

Набор собирается и проверяется ровно над одним выпуском SIMAI Framework.
Переход на новый выпуск — это новая сборка набора и новые проверки.
