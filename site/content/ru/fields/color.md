:::

## Цвет — `color`

| | |
|:---|:---|
| Значение | строка цвета, например `#1d4ed8` |
| В таблице и карточке | образец цвета и его код |
| В правке | образец, код, палитра `swatches` и кнопка сброса; с палитрой полю нужна вся строка карточки (`width: "full"`) — в половине строки образцы в этом выпуске не переносятся |
| Что уходит в сохранение | строка цвета |

| Настройка | Что задаёт |
|:---|:---|
| `swatches` | палитра: образцы в правке и варианты в фильтре |
| `inheritedValue` | цвет, унаследованный от темы, пока свой не выбран |
| `required` | запрещает очистку |
| `readonly` | поле только для чтения |
