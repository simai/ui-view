# Поля

Поле — одно свойство записи: название, сумма, дата, статус, ответственный,
файл. Таблица `sf-view-table` показывает поле в ячейке, карточка
`sf-view-properties` — для чтения и для правки. Как именно, решает **тип
поля**: приложение называет его в описании колонки или поля, а значение
передаёт в формате этого типа.

Типы — общие для всего SIMAI Framework: их рисует набор функций
`SF.fieldRenderers`, и список ниже взят из его реестра
`SF.fieldRenderers.registry` в выпуске, над которым собран SIMAI View.

## Все типы

| Тип | Название | Что хранит | Значение | Страница |
|:---|:---|:---|:---|:---|
| `string` | Строка | короткий текст; варианты: телефон, пароль | строка | [Текст](/ru/fields/text/) |
| `text` | Текст | многострочный текст | строка | [Текст](/ru/fields/text/) |
| `html` | Форматированный текст | текст с оформлением | строка HTML | [Текст](/ru/fields/text/) |
| `include` | Код | фрагмент кода | строка | [Текст](/ru/fields/text/) |
| `integer` | Целое число | количество, номер | число | [Числа](/ru/fields/numbers/) |
| `number` | Число | сумма, вес, процент; варианты: шкала, кнопки «−» и «+» | число | [Числа](/ru/fields/numbers/) |
| `date` | Дата | день | `ГГГГ-ММ-ДД` | [Дата и время](/ru/fields/dates/) |
| `datetime` | Дата и время | момент времени | ISO 8601 | [Дата и время](/ru/fields/dates/) |
| `time` | Время | время суток | `чч:мм` | [Дата и время](/ru/fields/dates/) |
| `boolean` | Да или нет | флажок | `true`, `false` | [Да или нет](/ru/fields/flags/) |
| `choice` | Одно из списка | статус, приоритет | значение варианта | [Выбор](/ru/fields/choice/) |
| `choices` | Несколько из списка | навыки, теги | массив значений | [Выбор](/ru/fields/choice/) |
| `lookup` | Из справочника | страна, город | `{value, label}` | [Выбор](/ru/fields/choice/) |
| `user` | Пользователь | ответственный, автор | `{value, label, avatarText, href}` | [Люди и связи](/ru/fields/links/) |
| `record` | Запись | ссылка на другую запись | `{value, label, href}` | [Люди и связи](/ru/fields/links/) |
| `relation` | Связь | связанная запись | `{value, label, href}` | [Люди и связи](/ru/fields/links/) |
| `file` | Файл | документы, изображения | `{label, mime, href, size}` или массив | [Файлы](/ru/fields/files/) |
| `color` | Цвет | цвет метки, бренда | строка цвета `#1d4ed8` | [Цвет](/ru/fields/color/) |

У каждого из восемнадцати типов есть просмотр и правка. В ячейке таблицы
свой вид есть у всех типов, кроме `text`: многострочный текст ячейка
показывает как есть, в одну строку. В окне фильтра таблицы свой элемент
есть у всех типов, кроме `html`, `time` и `include`: по ним фильтр ищет как
по тексту.

## Все типы на одной записи

Одна запись с полем каждого типа: в таблице, в карточке для чтения и в
карточке для правки. Переключатель над карточками меняет запись, третья —
с пустыми значениями. После «Сохранить» под карточками видно, что получило
приложение.

## Описание поля

Поле описывает приложение — в колонке таблицы или в группе карточки. Общие
ключи для всех типов:

| Ключ | Что задаёт |
|:---|:---|
| `key` | имя поля в записи |
| `label` | подпись |
| `propertyType` | тип; в ответе сервера таблице допустимо `property_type` |
| `variant` | вариант типа, например `phone` у строки или `scale` у числа |
| `required` | обязательное поле: отметка у подписи и проверка при сохранении |
| `readonly` | поле только для чтения: в правке оно показывается так же, как в просмотре |
| `width` | ширина в карточке: `half` — половина строки, `full` — вся строка |
| `value` | значение (в карточке); в таблице значение лежит в строке под `key` |

Остальные ключи у каждого типа свои — они на страницах типов.

## Значение

Значение передаётся в формате типа. Простое значение можно передать и как
`{value, text}`: `value` — данные, `text` — их запись, уже готовая к показу.

Даты и числа набор показывает так, как они пришли. Привычный вид — «15
ноября 2026 г.», «54 990,50» — даёт приложение функцией
`formatFieldValue(field, value)` в своём хосте, как в примерах на этих
страницах ([Формат дат и чисел](/ru/guide/concepts/data/)).

## Пустое значение

`null` или отсутствие ключа — поле не заполнено. В ячейке таблицы оно
пустое, в карточке для чтения — подпись «не заполнено» (слово задаёт
атрибут `empty-text` карточки), в правке — пустой элемент формы.

## Проверка

- `required` ставит отметку у подписи и не даёт сохранить пустое значение
  там, где элемент формы это умеет.
- Ограничения типа — `min`, `max`, `step`, маска строки — проверяет элемент
  формы при вводе.
- Окончательное решение за приложением: на `group.save` или `record.save`
  оно может ответить `refused` с `errors: {ключ: "сообщение"}`, и сообщение
  встанет под полем, а введённое останется.
