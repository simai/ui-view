# Числа

Два типа: целое число `integer` и число `number`. У обоих есть вариант
«Кнопками «−» и «+»» (`stepper`), у числа — ещё «Шкала 0–100» (`scale`).

:::

## Целое число — `integer`

| | |
|:---|:---|
| Значение | число |
| В таблице и карточке | число; единица `unit` — после него в карточке |
| В правке | поле ввода числа |
| Пустое | `null`; очищенное поле передаёт `null` |

| Настройка | Что задаёт |
|:---|:---|
| `unit` | единица после числа: `шт.`, `₽`, `кг` |
| `min`, `max`, `step` | границы и шаг — их читает вариант `stepper` |
| `required`, `readonly` | обязательное поле и поле только для чтения |

## Число — `number`

То же, что целое, и ещё `precision` — сколько знаков после запятой. Число
набор показывает так, как оно пришло (`54990.5`); вид «54 990,50» даёт
приложение через `formatFieldValue`, как в примере выше.

### Кнопками «−» и «+» — `variant: "stepper"`

Правка — поле количества `sf-quantity`: кнопки «−» и «+» и стрелки
клавиатуры. Шаг `step`, границы `min` и `max`; у числа — знаки
`precision` (без неё — по шагу, иначе два), у целого — без знаков после
запятой.

### Шкала — `variant: "scale"`

Число от 0 до 100, показанное шкалой с процентами: загрузка, готовность.
Шкале нужно само число, а не `{value, text}`.

## Проверка

- `min`, `max` и `step` ограничивают ввод варианта `stepper`.
- Обязательное поле `required` не сохраняется пустым.
- Остальные правила — например, что остаток не бывает отрицательным —
  проверяет приложение и отвечает на сохранение `refused` с сообщением у
  поля.
