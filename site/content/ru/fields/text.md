# Текст

Четыре типа для текста: строка `string` с вариантами «Телефон» и «Пароль»,
многострочный текст `text`, форматированный текст `html` и код `include`.

:::example {id="fields/text" label="Текстовые поля"}
:::

## Строка — `string`

Короткий текст в одну строку: название, имя, почта.

| | |
|:---|:---|
| Значение | строка |
| В таблице | текст в одну строку |
| В карточке | текст |
| В правке | поле ввода `sf-input` |
| Пустое | `null`; при `nullable: false` очищенное поле с маской передаёт `""` |

| Настройка | Что задаёт |
|:---|:---|
| `placeholder` | подсказка в пустом поле |
| `mask` | маска ввода в правилах масок SIMAI Framework (атрибут `mask-pattern` поля `sf-input`); значение — текст так, как он показан, вместе с постоянными символами |
| `nullable` | `false` — очищенное поле с маской передаёт пустую строку, а не `null` |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Проверка: с маской незаконченный ввод не становится значением — поле
сообщает, что ввод не завершён.

### Телефон — `variant: "phone"`

Строка с номером телефона. Значение — строка, например
`"+7 916 123-45-67"`. У телефона свой элемент ввода, поэтому настройку
`mask` этот вариант не читает: маска — только у обычной строки.

### Пароль — `variant: "password"`

Пароль, который никогда не показывается. Приложение передаёт не пароль, а
признак: `{set: true}` — задан, `{set: false}` или `null` — не задан. Таблица
и карточка пишут только «Задан» или «Не задан».

В правке — пустое поле с кнопкой «Показать пароль». Значение уходит в
сохранение, только когда человек ввёл текст; поле, которого не касались,
ничего не передаёт, поэтому сохранение не стирает заданный пароль. Если
пароль задан, `required` не действует, а очистить пароль через это поле
нельзя.

## Текст — `text`

Многострочный текст: описание, комментарий.

| | |
|:---|:---|
| Значение | строка; переводы строк сохраняются |
| В таблице | текст в одну строку с обрезкой; целиком — во всплывающей подсказке |
| В карточке | текст с переводами строк |
| В правке | многострочное поле |

Настройки: `placeholder`, `required`, `readonly`.

## Форматированный текст — `html`

Текст с оформлением: абзацы, заголовки, жирный и курсив, ссылки, списки,
цитаты.

| | |
|:---|:---|
| Значение | строка HTML из того подмножества, которое понимает `sf-input-rich` |
| В карточке | оформленный текст, очищенный по правилам `sf-input-rich` |
| В правке | редактор `sf-input-rich` с панелью оформления |
| В таблице | по реестру — текст без разметки в одну строку; в этом выпуске ячейка `sf-view-table` показывает разметку как есть (видно в примере выше) |

Настройки: `placeholder`, `required`, `readonly`. Фильтр по такому полю ищет
как по тексту.

## Код — `include`

Фрагмент кода или настроек.

| | |
|:---|:---|
| Значение | строка |
| В карточке | блок кода моноширинным шрифтом |
| В правке | многострочное поле |
| В таблице | первая строка кода |

| Настройка | Что задаёт |
|:---|:---|
| `language` | язык кода, атрибут `data-language` |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Фильтр по такому полю ищет как по тексту.
