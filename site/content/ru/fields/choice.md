# Выбор

Три типа: одно значение из списка `choice`, несколько значений `choices` и
значение из справочника приложения `lookup`.

## Варианты выбора

`choice` и `choices` берут варианты из `options` — массива `{value, label}`
(вместо `label` допустим `text`). Цвет метки варианта — `scheme` (или
`color`): схема SIMAI Framework — `primary`, `success`, `warning`, `error`,
`neutral` — или цвет в hex. Вид метки задаёт `badgeAppearance`, по
умолчанию `tonal`.

## Одно из списка — `choice`

| | |
|:---|:---|
| Значение | `value` одного из вариантов |
| В таблице и карточке | метка варианта с его цветом |
| В правке | выпадающий список |
| Что уходит в сохранение | значение выбранного варианта |

Настройки: `options`, `badgeAppearance`, `size`, `required`, `readonly`.

### Кнопками — `variant: "buttons"`

Правка — группа кнопок, по кнопке на вариант; `size` — ступень `1/2`, `1`
или `2`. Повторное нажатие на выбранную кнопку очищает необязательное поле.

## Несколько из списка — `choices`

| | |
|:---|:---|
| Значение | массив значений из `options` |
| В карточке | метки во всю ширину текста; не поместившиеся переносятся на следующие строки |
| В таблице | метки в строку; не поместившиеся сворачиваются в «+N» |
| В правке | до 12 вариантов — выпадающий список с отметками, от 13 — список флажков |
| Что уходит в сохранение | массив значений |

Настройки: `options`, `badgeAppearance`, `required`, `readonly`. Варианты
задают вид явно при любой длине списка:

- `badges` — метками;
- `checklist` — правка флажками, в две колонки, где поле достаточно широкое;
- `select` — правка выпадающим списком.

## Из справочника — `lookup`

Значение из справочника, который хранит приложение: страна, город, вид
договора. Это не ссылка на запись — из значения ничего не открывается.

| | |
|:---|:---|
| Значение | `{value, label}`; при `multiple` — массив таких объектов |
| В правке | выпадающий список вариантов |
| Что уходит в сохранение | `{value, label}` выбранного варианта или `null`; при `multiple` — массив |

| Настройка | Что задаёт |
|:---|:---|
| `options` | короткий справочник целиком — выбор прямо из него |
| `source` | имя справочника для приложения: большой справочник приходит страницами и ищется на сервере через запрос `field.options` |
| `multiple` | несколько значений |
| `placeholder`, `searchPlaceholder` | подсказки пустого поля и поиска |
| `required`, `readonly` | обязательное поле и поле только для чтения |
