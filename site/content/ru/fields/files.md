# Файлы

Тип `file` — один файл или несколько: документы, фотография, обложка,
галерея.

:::example {id="fields/files" label="Файлы"}
:::

## Файл — `file`

| | |
|:---|:---|
| Значение | `{label, mime, href, size}` или массив таких объектов; вместо `label` допустим `name`, вместо `mime` — `mimeType` |
| В карточке | список файлов: значок по типу, имя, размер и кнопка скачивания |
| В таблице | изображения — превью; в этом выпуске ячейка `sf-view-table` с документами остаётся пустой (видно в примере выше) |
| В правке | тот же список с кнопкой удаления у каждого файла и зона загрузки |
| Что уходит в сохранение | оставшиеся файлы и загруженные: массив, один файл или `null` |

| Настройка | Что задаёт |
|:---|:---|
| `multiple` | несколько файлов |
| `accept` | какие файлы принимать: `.pdf,.docx`, `image/*` |
| `formats` | список форматов в подсказке зоны загрузки |
| `uploadText`, `uploadSupportingText`, `uploadHint` | тексты зоны загрузки |
| `required` | читает только вариант `image`: пустое обязательное изображение не даёт сохранить |
| `readonly` | поле только для чтения |

### Изображение — `variant: "image"`

Одно изображение с превью. Правка одного изображения — поле
`sf-image-field`: оно передаёт выбранный файл и адрес превью, а после
«Убрать» — `null`.

### Изображение карточкой — `variant: "image-card"`

Изображение крупной карточкой.

### Изображения списком — `variant: "image-list"`

Несколько изображений рядом — галерея.

## Загрузка

Файлы загружает приложение. Карточка отправляет каждый выбранный файл
запросом `field.upload` и ждёт ответ `{answer: "applied", file: {label,
mime, href, size}}`; загруженный файл становится изменением поля и
сохраняется вместе с остальными по кнопке «Сохранить». Для этого хост
карточки объявляет возможность `field-upload`; без неё поле показывает свои
файлы только для чтения. Ответ `refused` с `message` показывается у файла,
и загрузку можно повторить.
