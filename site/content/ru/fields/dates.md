# Дата и время

Три типа: дата `date`, дата и время `datetime` и время суток `time`.

:::example {id="fields/dates" label="Дата и время"}
:::

Набор показывает дату так, как она пришла: `2026-11-15`. Привычный вид —
«15 ноября 2026 г.» — даёт приложение функцией `formatFieldValue`, как в
примере выше ([Формат дат и чисел](/ru/guide/concepts/data/)).

## Дата — `date`

| | |
|:---|:---|
| Значение | строка `ГГГГ-ММ-ДД` или дата со временем |
| В правке | календарь `sf-datepicker` |
| Что уходит в сохранение | строка даты; у значения со временем — новый день с прежним временем |
| Пустое | `null` |

Настройки: `required`, `readonly`.

## Дата и время — `datetime`

| | |
|:---|:---|
| Значение | ISO 8601: `2026-11-15T10:30:00`, с секундами, долями секунды и часовым поясом или без них; одна дата `ГГГГ-ММ-ДД` тоже читается |
| В правке | одна строка из двух полей: день — `sf-datepicker`, время — `sf-input` с маской `чч:мм` |
| Что уходит в сохранение | строка ISO 8601; `null`, когда оба поля очищены |

| Настройка | Что задаёт |
|:---|:---|
| `min`, `max` | границы: дата или дата со временем в ISO |
| `step` | шаг минут, от 1 до 60 |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Время можно ввести и без маски: `930`, `9:30` и `9.30` читаются как `09:30`.
Новый день сохраняет прежнее время вместе с секундами и часовым поясом;
новое время записывается с точностью до минуты.

**Ошибки ввода.** День без времени или время без дня — ошибка поля: под
строкой встаёт «Укажите время» или «Укажите дату», а сохранение не уносит
незаконченное значение. Когда ошибку исправили, сообщение уходит.

## Время — `time`

| | |
|:---|:---|
| Значение | время суток `чч:мм`, допустимы секунды и доли: `09:30:00` |
| В правке | поле времени |
| Что уходит в сохранение | `чч:мм`; если приложение хранит секунды — `чч:мм:00`; та же минута возвращается без изменений; очищенное поле — `null` |

| Настройка | Что задаёт |
|:---|:---|
| `min`, `max` | границы в виде `чч:мм` |
| `step` | шаг минут, от 1 до 60 |
| `required`, `readonly` | обязательное поле и поле только для чтения |

Фильтр по времени ищет как по тексту.
